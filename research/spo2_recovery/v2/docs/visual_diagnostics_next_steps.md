## 2. 当前 NRMSE 的计算方式与问题

当前代码中的 NRMSE 来自 `metrics.py::waveform_metrics`：

```text
NRMSE = ||estimate - reference||_2 / ||reference||_2
```

这里的 `reference` 是事件内伪真值波形，`estimate` 是 raw 或 recovered 波形。由于 Red/IR PPG 使用原始 ADC 码值，信号中包含很大的 DC 基线：

- Red 大约在 105000 ADC 附近。
- IR 大约在 153000 ADC 附近。
- 压力伪影和脉搏波变化通常只有几十到几百 ADC。

因此，`||reference||_2` 被巨大 DC 分量主导。即使波形形态仍有明显偏差，绝对 NRMSE 也会非常小。这解释了为什么当前指标看起来接近 `0.0006`，但视觉上仍能看到按压段残留抬升。

用重新计算的几种归一化方式对比：

| 通道 | 信号 | RMSE(ADC) | 当前绝对 NRMSE | 去均值 NRMSE | 按 5-95% 幅值归一 NRMSE |
|---|---|---:|---:|---:|---:|
| Red | raw | 133.27 | 0.001263 | 0.401 | 0.254 |
| Red | recovered | 45.42 | 0.000431 | 0.232 | 0.087 |
| IR | raw | 282.79 | 0.001841 | 0.679 | 0.349 |
| IR | recovered | 127.85 | 0.000832 | 0.443 | 0.158 |

这个结果更符合视觉感受：

- recovered 相比 raw 确实有恢复效果。
- 但如果按去均值形态或局部脉搏幅值衡量，误差并不小。
- IR 通道残留误差明显大于 Red，说明红外 PPG 对接触压力伪影更敏感，后续应重点处理 IR 的 DC/AC 稳定性。

结论：当前 NRMSE 可以作为粗略排序指标，但不适合作为主要科学评价指标。下一轮应至少同时报告：

- 去均值 NRMSE：关注波形形态。
- range-normalized RMSE：按局部脉搏/伪真值幅值归一。
- 峰值时序误差：收缩峰、谷值位置是否保留。
- AC/DC 比值稳定性：面向 SpO2 下游任务。
- 压力残留相关性：恢复后波形或 AC/DC 是否仍与 `Ut` 高相关。

## 3. 伪真值波形质量评估

新增的 `04-pseudo-truth-event-zoom.png` 显示，当前伪真值并不是理想的“干净 PPG 真值”，主要有以下问题。

### 3.1 伪波形存在端点贴合

当前伪真值构建中，为了保证事件窗口开头和结尾连续，会加入一条线性 `endpoint_error`，使合成波形端点贴近 observed：

```text
pseudo(t) = template_synthesis(t) + endpoint_error(t)
```

这带来一个副作用：如果事件检测边界已经落在压力伪影内部，伪真值也会在边界处继承 observed 的抬升或下降。于是边界误差会被低估，模型会更倾向于学习“贴近 observed 的伪真值”，而不是恢复真正的静息脉搏基线。

这与用户观察到的“边界处恢复效果没有区域中间好”一致。

### 3.2 伪波形局部趋势不一定合理

局部放大图中，部分事件的 pseudo 呈现较强线性趋势或缓慢抬升，例如 E4、E5、E6、E7 的 Red/IR 伪波形并非稳定的周期性脉搏模板，而是带有明显低频漂移。这会导致：

- 模型被允许在按压段保留一部分基线抬升。
- 视觉上 recovered 仍存在整段抬升。
- NRMSE 仍可较低，因为 pseudo 本身也带有抬升趋势。

### 3.3 伪波形相位和峰形存在不确定性

当前伪真值通过事件前后少量静息搏动模板插值得到。因为静息间隔短、可用搏动数少，模板相位、心率变化和峰形都可能不稳定。局部图中可以看到一些事件里 pseudo 的峰谷位置与 observed/recovered 不完全一致。

因此，当前伪真值更适合做“算法调试参考”，不适合直接作为最终恢复质量真值。

## 4. 恢复边界效果不佳的原因

目前恢复算法在事件窗口内生效，并在边界处使用 0.25 s 余弦渐入/渐出：

```text
recovered = observed * (1 - weight) + candidate * weight
```

其中 `weight` 在事件开始处从 0 逐渐升到 1，在事件结束处从 1 逐渐降到 0。

这样设计可以避免突变，但也会带来边界校正不足：

- 如果压力伪影在检测到的 `loading_start_s` 之前已经开始，边界前段不会被校正。
- 如果窗口开始/结束处仍有明显压力伪影，渐入/渐出会削弱校正强度。
- 如果伪真值端点又贴近 observed，模型训练时也不会强烈惩罚边界残留。

下一轮可尝试：

1. 将校正窗口相对检测窗口向前/向后扩展，例如各扩展 0.3-0.8 s。
2. 事件边界不以 hard mask 控制，而是使用连续压力权重，例如由 `Ut_common` 响应归一化得到 `pressure_weight(t)`。
3. 伪真值不再强制贴合 observed 端点，而是使用按压前后静息 DC/AC 趋势外推。
4. 分别评估窗口中部误差和边界误差，避免整体平均掩盖边界问题。

## 5. 面向 SpO2 下游任务的关键波形特征

SpO2 的经典 ratio-of-ratios 依赖：

```text
R = (AC_red / DC_red) / (AC_ir / DC_ir)
SpO2 = A - B * R
```

因此，波形恢复不应只追求形状好看，还要保护以下特征：

1. Red/IR 的 DC 水平

   DC 代表光路、组织吸收和接触状态的慢变化。压力伪影会改变 DC，但过度校正也可能破坏真实慢变趋势。

2. Red/IR 的 AC 幅值

   AC 幅值用于估计脉搏吸收变化。当前按压会放大或压缩 AC 包络，因此仅做基线扣除是不够的。

3. AC/DC 比值

   单通道恢复好不等于 SpO2 稳定。需要检查：

   ```text
   red_ac / red_dc
   ir_ac / ir_dc
   (red_ac / red_dc) / (ir_ac / ir_dc)
   ```

4. 收缩峰和舒张谷的位置

   如果恢复过程改变峰位置或引入假峰，即使 NRMSE 降低，也会影响逐搏 AC 估计。

5. Red 与 IR 的相对相位和共同心搏结构

   SpO2 应在同一心搏上估计 Red/IR 的 AC/DC，因此两通道峰谷配对非常重要。

6. 与压力参考信号的残留相关性

   恢复后，PPG 的 DC、AC 包络、AC/DC 或 R 序列不应仍与 `Ut1`/`Ut2` 高度相关。否则说明压力伪影仍残留。

## 6. 下一步算法开发建议

### 6.1 先升级评价体系

下一轮建议先不急着换复杂模型，而是把评价指标从“伪真值 NRMSE”升级为多指标面板：

- `absolute_nrmse`：保留当前指标，仅作参考。
- `centered_nrmse`：去均值形态误差。
- `range_nrmse`：按局部脉搏幅值归一的误差。
- `boundary_nrmse`：事件边界前后 0.3-0.5 s 的误差。
- `middle_nrmse`：事件中部误差。
- `peak_timing_mae`：收缩峰时间误差。
- `peak_amplitude_error`：逐搏 AC 幅值误差。
- `ratio_of_ratios_cv`：按事件/逐搏的 R 值变异系数。
- `pressure_residual_corr`：恢复后 AC/DC/R 与 Ut 的相关性。

这样可以避免出现“NRMSE 很小但视觉不好”的假象。

### 6.2 改造伪真值

当前伪真值主要用于起步验证。下一步建议：

1. 去掉或弱化 endpoint anchoring，避免伪真值继承 observed 的压力抬升。
2. DC 使用按压前后静息段的稳健趋势外推，而不是在事件内线性贴合 observed。
3. AC 模板按逐搏相位生成，但幅值由前后静息包络插值，不从按压段吸收信息。
4. 给每个事件输出伪真值质量评分，质量差的事件不参与模型排序，只用于视觉诊断。

### 6.3 改进边界恢复

针对用户指出的边界问题，建议：

- 将事件窗口扩展为 `analysis_window` 和 `correction_window` 两层。
- 用 Ut 响应幅度构造连续校正权重，而不是只用二值 mask。
- 允许 DC artifact 在边界处非零，但要求其一阶导数连续。
- 单独报告边界误差，作为模型选择约束。

### 6.4 面向 SpO2 的恢复目标

最终目标不是让 PPG 看起来最平滑，而是让 SpO2 相关特征稳定。下一阶段可把模型目标改成：

1. 先恢复 DC 和 AC envelope，使 Red/IR 的 `AC/DC` 在按压前、按压中、松开后保持连续。
2. 再保持脉搏 AC 形态，不引入假峰或峰位偏移。
3. 最后计算逐搏 `R` 序列，看恢复后按压事件中的 R 是否更接近前后静息水平。

推荐下一轮实验主题：

```text
从“拟合伪真值波形”转向“稳定 Red/IR AC/DC 与 ratio-of-ratios 的压力去耦”
```

这更贴近血氧饱和度任务，也能避免单纯波形模板插值带来的评价偏差。
