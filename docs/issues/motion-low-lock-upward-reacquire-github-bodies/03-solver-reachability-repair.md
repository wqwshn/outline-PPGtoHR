## What to build

将 replay 中稳定的运动段低锁上跳策略落入 v2 solver。机制触发后优先执行可达性修复，不直接硬改 Final HR；同时输出候选过滤、评分、修复动作和失败快速退出诊断字段，并保持 KLMS 默认生产语义谨慎。

## Acceptance criteria

- [ ] 低锁上跳机制只在运动段 adaptive 谱峰追踪路径中生效。
- [ ] 触发需要低锁背景、真实上升证据、候选资格过滤通过和候选相对评分通过。
- [ ] 触发后的主要动作是修复搜索范围、追踪中心或候选可采纳性，而不是直接硬改 Final HR。
- [ ] 候选进入可达区域后仍需要接受正常候选选择和后处理约束。
- [ ] 候选失稳、候选不再合格、搜索范围持续远离合理区域或疑似伪峰污染时，机制快速退出。
- [ ] `window_table.spectrum_tracking` 输出低锁上跳状态、候选、过滤原因、评分摘要、可达性修复动作和退出原因。
- [ ] KLMS 生产默认不启用低锁上跳和高频逃逸，只有实验 allowlist 能打开。
- [ ] 高频锁定逃逸与低锁上跳继续分开评估，不合并为一个机制开关。
