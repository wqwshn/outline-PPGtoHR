## What to build

在 Stage 1 胜出的简单自适应器上贯通宽带双侧质量感知联合。每侧 HF 使用因果无标签证据描述参考活动、对 PPG/残差的可解释比例、两侧共线程度、HF—PPG 映射稳定性以及饱和、近常量或异常噪声。质量量用于调节每通道正则化和最大消除贡献，避免无条件双侧联合被坏通道或病态输入污染。

本切片必须从合成故障场景贯通到场景三折训练/留出记录，并与固定单侧和无条件双侧候选做公平消融；不得使用参考 HR、人工运动标签或测试后较优通道选择作为运行时证据。

## Acceptance criteria

- [ ] 公共配置可以选择宽带质量感知双侧联合，并保持完整记录运行器的输入输出契约不变。
- [ ] 通道质量只依赖当前/历史 PPG、HF、残差、预测伪影和允许的固定前视；诊断日志能够证明无参考 HR/人工标签依赖。
- [ ] 质量量至少覆盖参考活动、残余可解释性、两侧共线、映射稳定性和异常通道状态。
- [ ] 质量不足时通过正则化或贡献上限连续降权；硬剔除只用于明确故障保护，不允许测试后择优单侧。
- [ ] 合成测试覆盖单侧常量、饱和、高噪声、两侧共线、低能量和映射突变，并验证输出有限、确定且不过度消除已知脉搏分量。
- [ ] 真实记录消融公平比较无条件双侧、固定 HF1/HF2 与质量感知双侧，保存逐窗质量、通道贡献和失败标签。
- [ ] 训练折内只保留稳定参数平台；留出结果按记录等权、场景分层报告，不直接池化窗口。
- [ ] 候选必须推动频谱—MAE Pareto 前沿才能进入分频阶段，否则明确回退到 Stage 1 简单候选。
- [ ] 相关窄测试、回归测试和完整记录工件验证在 conda `ppg-hr` 环境通过。
