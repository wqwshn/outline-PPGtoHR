## What to build

在统一完整记录接缝、场景三折、输出尺度和固定 Lite 追踪器下完成 HF 消伪最小因子拆分。按顺序只改变一个因素：先在旧级联结构中比较 LMS 与匹配 NLMS 更新，再固定更新比较逐路级联、无条件双侧联合和固定单侧，最后固定更新与结构比较 W0、W1 和单一指数软遗忘。

每个因素都必须从配置贯通到真实记录频谱证据、HR 结果、记录/场景汇总和淘汰结论，避免再次把更新算法、联合结构、权重状态与 BO 缺失混为一个完整候选。

## Acceptance criteria

- [ ] LMS/NLMS 比较保持通道结构、归一化、物理记忆、前视、权重状态和追踪器一致。
- [ ] 级联/联合/单侧比较保持更新律、参数选择和追踪器一致，且不在测试记录后选择较优单侧。
- [ ] W0、W1 与单一软遗忘保持滤波参数一致；W1 只更新新到达样本，不重复训练重叠窗口。
- [ ] 每个候选分别输出真实峰突出度、Rank-1/Top-3、心率带占比、跨窗稳定性、MAE、E10/E20 和失锁比例。
- [ ] 频谱证据与下游指标不压缩为加权总分，参数选择遵循频谱门槛优先的字典序和稳定平台规则。
- [ ] 每个因素形成可复核的配对表、场景分层结果、频谱—MAE Pareto 关系和明确保留/淘汰理由。
- [ ] 合成边界与至少一条完整真实记录的行为测试按 TDD 先红后绿；其他滤波策略保持回归通过。
- [ ] 复杂候选未推动 Pareto 前沿时回退简单候选，不为进入下一阶段强留机制。
- [ ] 相关窄测试和完整记录工件验证在 conda `ppg-hr` 环境通过。
