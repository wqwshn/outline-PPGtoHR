## What to build

贯通 HF 消伪研究的完整记录公共接缝：从冻结配置和场景折次清单运行一条真实记录，输出逐窗频谱证据、固定 Lite 追踪 HR、记录/场景汇总、QC 与可追溯 manifest。建立场景内留一记录三折和全场景统一参数三折，并以完全相同的数据隔离运行旧 Lite 场景三折基线；旧 Lite 单记录 BO 仅作为拟合上限另行输出。

本切片同时建立新研究 worktree、尺度契约和测试参考 HR 无泄漏保护，为后续所有机制提供唯一主测试接缝。

## Acceptance criteria

- [ ] 新研究分支继承上一轮研究提交的实验基础设施并引入已批准 spec/PRD/ADR，工作树起点洁净且基准、分支、绝对路径和提交可追溯。
- [ ] 场景内三折使每个场景的每条记录恰好作为一次留出记录，折次参数只能来自另外两条记录。
- [ ] 全场景统一参数三折每折留出 8 个场景的同一重复编号记录，另外 16 条记录用于学习共享参数。
- [ ] 完整记录运行器通过一个公共接口输出逐窗证据、完整 HR、记录/场景汇总、QC、配置哈希与 manifest。
- [ ] 自动检查证明测试参考 HR、留出指标和人工标签未进入参数选择或运行时机制。
- [ ] 旧 Lite 场景三折基线与新机制共享窗口、参考对齐、追踪器和折次隔离；单记录 BO 拟合上限明确标记为不可部署对照。
- [ ] 跨方法主比较使用尺度不变指标；尺度契约不满足时拒绝绝对功率比较。
- [ ] 使用公共完整记录接缝完成至少一个先红后绿的集成测试，并覆盖确定性重放、缺失输入和非有限输出。
- [ ] 相关窄测试在 conda `ppg-hr` 环境通过，且基线产物可从保存配置重放。
