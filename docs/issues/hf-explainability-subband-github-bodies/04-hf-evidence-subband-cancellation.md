## What to build

在通过 Stage 2 的基础候选上贯通 HF 证据驱动的分频消伪。首版将 0.5–3.5 Hz 固定划分为六个 0.5 Hz 子带，每个子带独立估计双侧 HF 对 PPG/残差的可解释性和映射稳定性，并约束该带预测伪影的贡献。缺乏 HF 证据的子带保持保守，参考 HR 只用于离线频谱验收，不能用于运行时选带或保护频带。

本切片依次比较宽带无条件双侧、宽带质量感知、分频固定强度和质量感知分频联合，并预注册 0.25/1.0 Hz 带宽敏感性，不允许根据留出结果择优。

## Acceptance criteria

- [ ] 公共配置可以选择六个固定 0.5 Hz 子带的自适应消伪，并保持完整记录运行器契约与输出尺度可追溯。
- [ ] 子带分析—重构对已知信号保持允许误差内的幅值与时序；关闭消除时可重构原输入。
- [ ] 每个子带质量只使用因果无标签 HF/PPG/残差证据，不读取参考 HR、人工运动标签或留出结果。
- [ ] 质量为零时对应子带不发生强消除，证据充分时行为退化为相应基础自适应器。
- [ ] 合成测试覆盖单频伪影、多带伪影、真实脉搏与伪影相邻、坏单侧和无 HF 支持竞争峰，并验证选择性消除与脉搏保护。
- [ ] 嵌套消融按同一三折、追踪器和尺度口径输出频谱证据、MAE、子带质量、子带贡献和失败桶。
- [ ] 主结果固定 0.5 Hz；0.25 和 1.0 Hz 只做预注册敏感性分析，不改变主候选。
- [ ] 只有质量感知分频相对更简单候选产生稳定实际收益时才保留组合复杂度。
- [ ] 相关窄测试、回归测试和完整记录工件验证在 conda `ppg-hr` 环境通过。
