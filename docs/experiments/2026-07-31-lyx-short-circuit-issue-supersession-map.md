## 1. 最新决策优先级

原 issues 基于“完整跑满恢复 × 惩罚 × 八档滤波矩阵，再进入三折重放”的路线。
用户随后明确批准：

1. 不再机械跑满 36 个独立 BO 单元；
2. `run3` 自然封存后停止旧监督器；
3. 采用困难样本优先、首个 `0/150` 即淘汰的 Gate A；
4. 只有存在 `fs_target=25` survivor 时才运行 Gate B；
5. Gate B 直接验证场景内共享参数选择，不把开发复用记录称作算法级留出或
   迁移验证；
6. 禁止重算已完成身份或自动重试失败身份。

## 3. GitHub 关闭语义

- #102、#104 最终应以“被用户批准的新短路设计取代”关闭，而不是勾选未运行的
  旧矩阵验收项；关闭评论必须链接短路 spec、proposal 和最终报告。
- #105 只有在 Gate B 实际完成 12 折时才可按实现完成关闭；若 Gate A 无
  survivor，则按预注册停止规则关闭为“不执行 Gate B”，并保留失败结论。
- #106 只有最终报告、独立 BO 判断和挑战场景移交包均落盘后才可关闭。
- 跨个体与未见场景验证继续留给后续 Issue #13，不属于本轮完成条件。
