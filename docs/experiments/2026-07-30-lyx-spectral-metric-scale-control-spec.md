# LYX Stage R 频谱指标量纲对照实验规范

## 1. 决策摘要

本实验不继续搜索滤波参数，也不重跑 Stage R。它只回答一个先决问题：
上一轮 36 个 p25 诊断全部丢失脉搏功率，究竟是 LMS 恢复机制真实损伤了
脉搏，还是频谱相对指标把原始尺度的滤波前信号与标准化尺度的滤波后信号
直接相除，造成了量纲错配。

实验冻结为 12 个逐记录诊断身份，覆盖 LYX 的写字、敲键盘、跑步和开合跳
四个场景，每个场景 3 条记录。每个身份内部运行三条确定性对照，不进行
参数搜索：

1. 原始信号直通；
2. 原始尺度滤波前信号对零更新 LMS 输出，即复现当前旧评估面；
3. 标准化尺度滤波前信号对同一零更新 LMS 输出，即同量纲评估面。

本规范发布时只生成零运行 proposal：
`1c3fcc909fbbc5d9d79c3ce07d93e7c77d086efa96e37a1752de4884da885107`。
真实 12 条记录的执行必须等待该精确哈希审批。

## 2. 上游证据与问题边界

上游 p25 诊断冻结为：

- proposal：
  `db1f5d2278458592c08d7e6217d52090a8ab1f94b96262de99e84a466e2c6128`；
- completion：
  `81171332c7c29e80f329c9140874480321bf101ca7f91c853c3ae453015251ac`；
- decision：
  `29f042e080441ae979fea32e0b38c9de8ac778fc71d3bd5d99d78ba8ba763f55`。

36 个 p25 坐标中，`pulse_power_retention_pass` 为 0/36；其他频谱门并非
一致失败。因此不能直接把结论解释为“所有 p25 滤波组合都破坏脉搏”，必须先
审计相对功率指标的尺度一致性。

本实验只复用开发集证据，不构成算法级 holdout，不得提名恢复候选，不得自动
进入 Stage R 或 Stage F，也不得触发独立 BO。

## 3. 身份与数据面板

身份粒度为“记录”，共 12 个：

| 场景 | 记录数 | 角色 |
| --- | ---: | --- |
| 写字 `xiezi` | 3 | 低运动、平稳心率恢复 |
| 敲键盘 `jianpan` | 3 | 低运动、平稳心率恢复 |
| 跑步 `run` | 3 | 强周期运动、生理心率波动 |
| 开合跳 `kaihe` | 3 | 强非平稳运动、生理心率波动 |

每个身份绑定原始数据哈希、参考心率文件哈希、上游 p25-short-low 身份哈希、
运行源代码哈希、评估源代码哈希、量纲对照合同哈希和 v7 预算合同哈希。

固定使用 `p25-short-low`：

- `fs_target = 25 Hz`；
- 物理记忆长度 `40 ms`；
- 实际阶数 `M = 1`；
- 两级 LMS 均强制 `mu = 0`。

选择 `M = 1` 是为了消除高阶滤波初始区间和自适应更新的干扰。该设置不是
候选滤波档位，也不参与性能比较。

## 4. 三条确定性对照

三条对照共享完全相同的 Stage R 窗口、参考心率、延迟估计、参考通道排序和
运动参考：

| 对照 | before | after | 用途 |
| --- | --- | --- | --- |
| `direct_raw_bypass` | 原始 PPG | 同一原始 PPG | 检查频谱计算器自身是否保持单位输入 |
| `legacy_raw_vs_zero_update_lms` | 原始 PPG | 零更新 LMS 输出 | 复现当前原始/标准化混算面 |
| `same_scale_zero_update_lms` | LMS 精确样本 z-score PPG | 同一零更新 LMS 输出 | 检查同量纲零更新路径 |

LMS 的输入标准化必须调用生产代码的同一个 `standardize_lms_signal` 实现，
不能在实验脚本里另写近似公式。所有 LMS 权重必须精确保持为零。

## 5. 冻结阈值

阈值在真实 12 条对照运行前冻结：

| 判据 | 阈值 |
| --- | --- |
| 直通脉搏功率保留率 | `[0.999999, 1.000001]` |
| 同量纲零更新脉搏功率保留率 | `[0.95, 1.05]` |
| 旧量纲/同量纲保留率比值 | `≤ 0.10` 记为该记录复现量纲错配 |
| 完整性 | 每条记录三条对照均无不可计算窗口 |
| 面板完整性 | 必须为 12/12 条记录 |

这些阈值只判断实现机制，不替代原 Stage R 五项频谱门。

## 6. 决策树

按以下优先级一次性冻结决策：

1. 任一记录直通失败或窗口证据不完整：
   `spectral_evaluator_invalid`，先修频谱评估器；
2. 直通全部通过，但任一记录同量纲零更新失败：
   `zero_update_path_invalid`，先修零更新/级联路径；
3. 直通与同量纲均 12/12 通过，且旧量纲错配 12/12 复现：
   `legacy_scale_mismatch_confirmed`，进入频谱指标量纲修订设计；
4. 旧量纲错配仅 1–11/12 复现：
   `legacy_scale_mismatch_partial`，逐记录审查尺度与窗口条件；
5. 旧量纲错配 0/12：
   `legacy_scale_mismatch_not_reproduced`，返回滤波机制诊断。

任何分支都不自动重写既有 36 个 p25 原始结果。若确认量纲错配，旧结果保留为
历史证据，后续需另行设计“修正评估器后的重分类或有限重算”方案。

## 7. v7 预算修订

v7 只增加 12 个诊断身份：

| 项目 | v6 | proposed v7 |
| --- | ---: | ---: |
| 正常身份上限 | 780 | 792 |
| 全局唯一身份上限 | 792 | 804 |
| 最坏尝试上限 | 1584 | 1608 |
| 单身份重试上限 | 1 | 1 |
| 新 stage 上限 | 0 | 12 |

新 stage 为 `spectral_metric_scale_control_diagnostic`，attempt kind 为
`diagnostic`。每个身份内部的三条对照是同一次确定性诊断的组成部分，不拆成
三个求解身份；否则会把同一数据加载和同一窗口准备重复计费，并削弱配对解释。

控制结果。独立 BO 仍为人工审核项，且本实验没有触发它的科学理由。
