# SpO2 连续自适应波形恢复设计

## 背景

当前 v2 血氧计算先在每个 4 s 窗口内执行幅值保持的因果 LMS 清洗，再用同一窗口计算 SpO2。这个路径对短窗内快速收敛要求很高，且每个窗口都会重新初始化滤波器，导致手腕弯曲这类连续运动伪影恢复不明显。

参考论文 `10.1109/TIM.2011.2175832` 的核心思想是：先利用运动伪影参考信号通过自适应滤波恢复 Red/IR PPG 波形，再比较恢复前后的 SpO2。本文献需要从 PPG 内部生成伪影参考；本项目已有 `Ut1/Ut2` 等传感器直接表征接触距离/压力对 PPG 光路的影响，因此本设计不复刻论文的 FFT/SVD/ICA 参考生成步骤，而是复用项目现有参考信号体系。

## 目标

直接替换 v2 血氧计算中的旧自适应清洗路径：先对完整运动段进行连续 Red/IR PPG 波形恢复，再用现有 4 s 窗口峰谷法计算恢复前后的 SpO2。

成功标准包括两类：

1. 波形层面：手腕弯曲期间，恢复后的 Red/IR 波形应恢复出更稳定的峰谷结构，参与 SpO2 计算的有效搏动数不应下降。
2. SpO2 层面：假设短时间手腕摆动不引起真实血氧大幅变化，恢复后运动段 SpO2 应更接近运动前后静息段的范围，逻辑参考论文 Fig. 19。

## 范围

本次改动覆盖：

- `python/src/ppg_hr/v2/spo2.py` 的自适应恢复流程。
- v2 血氧 GUI 页面中的自适应滤波算法选择。
- v2 血氧报告中的恢复诊断字段。
- v2 血氧可视化，新增验证用 PNG 图。
- `python/tests/test_v2_spo2.py` 和相关 GUI smoke 测试。
- README 中 v2 血氧说明。

本次不做：

- 不接入外部脉搏血氧仪真值。
- 不对 SpO2 二次标定公式做优化。
- 不保留旧的 4 s 窗口内幅值保持 LMS 路径。
- 不默认输出 PDF/SVG/TIFF；验证阶段只输出 PNG。

## 算法设计

### 1. 输入预处理

读取 CSV 时保留原始 Red/IR、Ut1/Ut2、CF、ACC 波形用于报告和绘图。进入自适应滤波前，对 `PPG_Red`、`PPG_IR`、`Ut1`、`Ut2`、CF 和 ACC 参考通道执行鲁棒去毛刺。

去毛刺只替换孤立尖峰：使用滑动中位数和 MAD 判定离群点，并用局部中位数替换。连续运动导致的基线变化不视为毛刺，不能被去毛刺步骤抹平。报告记录每个通道被替换的点数和比例。

### 2. 运动段识别

窗口长度仍使用血氧窗口配置，默认 4 s，步长默认 1 s。运动评分仍以加速度计为主，计算 `acc_mag = sqrt(accx^2 + accy^2 + accz^2)` 的窗口标准差。

阈值不再只依赖固定 `rest_motion_score_threshold=0.02`。新流程从全段窗口评分估计静息基线，使用低分位数窗口的中位数和 MAD 得到数据内阈值，并和配置阈值共同决定运动窗口。连续运动窗口合并为运动段，并加入前后缓冲，作为连续自适应恢复区域。

### 3. 连续自适应恢复

对每个运动段加缓冲后的恢复区域，分别恢复 Red 和 IR。恢复区域内滤波器连续运行，不在每个 4 s SpO2 窗口内重新初始化。

自适应滤波策略复用批量全流程的选择：

- `lms`
- `as_lms`
- `klms`
- `volterra`
- `noncausal_lms`
- `rff_lms`

血氧 GUI 增加同样的下拉框，默认 `lms`。专属参数先沿用现有默认值，不在血氧页面展开复杂参数面板。

### 4. 参考信号级联

参考组顺序继续由用户选择，默认 `HF -> CF -> ACC`。每个参考组内部按相关性排序后级联滤波，保持和 v2 心率算法一致。

因为血氧恢复同时处理 Red 和 IR，组内排序使用 Red/IR 的联合相关性：分别计算参考通道与当前 Red、IR 残差信号在恢复区域内的最大绝对相关，取两者的稳健汇总分数排序。Red 和 IR 使用同一参考级联顺序，避免两路信号被不同通道顺序清洗后破坏比值关系。

HF/CF 参考使用因果抽头 `K=0`；ACC 参考按现有 v2 规则允许有限前馈抽头。每一级记录通道名、组名、相关性、延迟、阶数、前馈抽头、滤波器类型和输出长度。

### 5. 不做幅值保持

新路径不强制保持原始 PPG DC 基线，也不执行中位数平移。运动伪影本身可能体现为基线和光路变化，强行保留原基线会削弱恢复效果。

自适应滤波输出经必要的长度对齐和有限值保护后，直接作为恢复波形进入 SpO2 计算。若某个滤波策略输出长度短于恢复区域，则按现有策略对齐有效部分，并在报告中记录被截短的样本数。

### 6. SpO2 计算

SpO2 计算方法保持不变：

1. IR 带通信号确定心搏周期。
2. Red 在同一 IR 周期内做局部峰谷修正。
3. Red/IR 低通 ADC 路径保留 DC。
4. 谷-峰-谷连线法计算 AC/DC。
5. 窗口内取 `R = (ACred/DCred)/(ACir/DCir)` 中位数。
6. 用现有二次公式计算 SpO2。
7. 对窗口序列做 7 s 居中平均。

不同之处是：运动窗口的 adaptive SpO2 来自连续恢复后的整段波形切窗，而不是窗口内短程滤波输出。静息窗口仍以 raw SpO2 为最终值，但报告保留恢复波形用于视觉检查。

## 可视化设计

使用 Python/matplotlib，遵循 `nature-figure` 的证据优先原则。验证阶段只输出 PNG，默认 600 dpi。

核心结论：连续自适应恢复能让手腕弯曲期间的 PPG 峰谷形态和 SpO2 回到静息前后合理范围。

至少输出三类图：

1. 整段波形恢复图：Red/IR 原始与恢复波形，叠加运动段阴影，并显示 Ut1/Ut2 或运动评分作为辅助证据。整段多面板图使用双栏宽度。
2. 局部切片图：手腕弯曲前、弯曲中、弯曲后各取代表窗口，展示恢复前后 Red/IR 波形和峰谷标记。单个切片或紧凑对比使用单栏宽度。
3. SpO2 对比图：raw 与 adaptive SpO2 趋势，标出运动段和前后静息范围，强调运动段恢复后是否回到合理范围。

## 测试策略

测试采用 TDD。

1. 合成数据测试连续恢复：构造静息-运动-静息 Red/IR，运动段加入与 Ut1/Ut2 相关的伪影，验证连续恢复后与参考伪影的相关性下降，且有效搏动数不下降。
2. 运动段识别测试：构造加速度静息-运动-静息评分，验证自适应阈值能合并连续运动窗口，并产生带缓冲恢复区域。
3. 去毛刺测试：构造孤立尖峰和连续基线漂移，验证只替换孤立尖峰，不抹掉连续漂移。
4. 滤波策略分发测试：对 `lms/as_lms/klms/volterra/noncausal_lms/rff_lms` 至少验证配置可分发、输出有限、长度可对齐。
5. SpO2 稳定性测试：合成短时间运动不改变真实 SpO2 的场景，验证恢复后运动段 SpO2 更接近前后静息范围。
6. 真实 CSV 冒烟测试：使用 `research/spo2_recovery/data/raw_data_20260608_191821.csv` 跑通血氧求解和 PNG 生成，验证报告中包含运动段、滤波策略和恢复诊断。

## 风险与缓解

- 风险：去毛刺误删真实运动段变化。缓解：只处理孤立尖峰，并在报告中记录替换点。
- 风险：非幅值保持滤波可能过度改变 Red/IR 比值。缓解：同时报告峰谷有效数、R 值、SpO2 相对静息偏差，并保留 raw 对比。
- 风险：不同滤波策略输出长度不同。缓解：统一长度对齐和诊断记录。
- 风险：没有外部 SpO2 真值，无法证明绝对准确。缓解：以短时间运动段相对前后静息一致性作为验证指标，并明确这是恢复有效性的内部证据。
- 风险：PNG 图过宽或信息过密。缓解：整段图用双栏，局部切片图用单栏，避免把所有证据塞进一张图。
