# Phase 2：面向血氧解算的接触压力伪影恢复设计

日期：2026-06-10

## 1. 背景与目标

当前 `research/spo2_recovery/v2` 已完成第一阶段伪真值构建与边界过渡修订。实验结果显示，恢复信号相比原始 observed 信号能够暴露部分按压段内的 PPG 收缩峰，但伪真值仍只能作为参考：边界连续性、局部抬升、以及恢复后可能出现的双肩峰，都说明仅用伪真值 NRMSE 评价波形恢复并不充分。

Phase 2 的目标是把评价重心转向最终下游任务：血氧饱和度解算。恢复算法不只追求贴合伪真值，而应优先稳定与 SpO2 计算相关的 PPG 特征，包括 Red/IR 的 AC/DC、R 值、峰谷定位、峰间期和按压段边界连续性。

本阶段仍坚持白盒信号处理算法，要求每个候选方法的输入、特征、参数和校正机制可解释。

## 2. 输入信号研究设计

热式界面传感器信号必须作为算法研究变量纳入，但不预设两路 Ut 必须同时进入同一个模型。由于 PPG 两侧对称布置了 Ut1 与 Ut2，按压干扰可能主要表现为整体接触压力变化，此时单路 Ut1 或 Ut2 可能已经足够；也可能存在左右不均匀接触、倾斜或局部翘起，此时共模/差模或双路组合才有额外收益。

因此 Phase 2 将对比以下输入组：

1. `ut1_only`：`[Ut1, dUt1/dt]`
2. `ut2_only`：`[Ut2, dUt2/dt]`
3. `common_only`：`[C, dC/dt]`，其中 `C = (Ut1 + Ut2) / 2`
4. `difference_only`：`[D, dD/dt]`，其中 `D = (Ut1 - Ut2) / 2`
5. `common_difference`：`[C, dC/dt, D, dD/dt]`
6. `raw_pair`：`[Ut1, dUt1/dt, Ut2, dUt2/dt]`

其中 `common_difference` 与 `raw_pair` 在信息量上近似等价，区别在于坐标表达方式不同。`common` 表示左右两侧共同感受到的整体接触压力/间隙变化；`difference` 表示左右不对称压力、倾斜或侧向受力。该变换可逆：

```text
Ut1 = C + D
Ut2 = C - D
```

所以 `common_difference` 不是丢弃 Ut1/Ut2，而是把两路信号转换为更符合硬件空间布局的对称/反对称坐标。

## 3. 候选算法范围

Phase 2 减少 FIR 网格探索，不再把上一轮表现较差的大量 FIR 组合作为主线。保留上一轮表现较好的白盒基线，用于和新增自适应方法对比。

候选算法分为三类：

1. 基线方法
   - `raw_observed`：不恢复，直接计算指标。
   - 上一轮较优的 `hammerstein_fir` 或 `hysteresis_spline`，只保留少量代表性配置。

2. 短事件自适应滤波
   - `nlms`：归一化 LMS，步长随输入能量归一化，降低短按压段中普通 LMS 收敛慢或发散的风险。
   - `rls`：递归最小二乘，适合短时间内快速收敛，但需要正则化、低阶数和遗忘因子约束。
   - `regularized_batch_adaptive`：在每个事件加缓冲区内进行局部批量拟合，然后用平滑权重拼接，优先追求离线恢复效果。

3. 事件级白盒校正
   - 面向 DC/AC 或低频基线伪影建模，而不是直接让滤波器学习完整 PPG 波形。
   - 优先解释压力变化如何影响 PPG 基线、包络和 AC/DC 比值。

普通长阶 FIR 与需要长时间充分收敛的 LMS 不是本阶段重点；若保留，只作为对照或退化基线。

## 4. 短按压事件与边界处理

当前按压区域时间较短，自适应滤波存在明显收敛风险。Phase 2 采用事件级处理策略：

1. 每个按压事件的校正窗口向前、向后扩展缓冲区，初始候选范围为 `0.5-1.0 s`。
2. 在核心按压段之外的缓冲区使用平滑窗渐入渐出，避免恢复信号在边界处突变。
3. 对自适应滤波设置低阶模型和受限参数，优先保证稳定性，而不是最大化模型自由度。
4. 对离线算法允许双向或局部批量拟合，但输出必须保持可解释，不能依赖黑盒神经网络。
5. 边界质量作为硬指标纳入评分，重点监控按压进入和松开后的双肩峰、台阶跳变和异常尖峰。

## 5. SpO2 下游评价指标

Phase 2 的核心评价从伪真值 NRMSE 转向血氧相关特征稳定性。

SpO2 计算仍使用 MAX30101 厂商二次公式：

```text
SpO2 = a R^2 + b R + c
```

其中 R 值来自 Red/IR 的归一化 AC/DC 比：

```text
R = (AC_red / DC_red) / (AC_ir / DC_ir)
```

评价指标包括：

1. `R_event_shift`：按压段 R 值相对邻近静息段的偏移。
2. `SpO2_event_shift`：按压段 SpO2 相对邻近静息段的偏移。
3. `R_cv` 与 `SpO2_cv`：按压段内 R 与 SpO2 的变异系数。
4. `valid_beat_count`：参与 SpO2 计算的有效搏动数量。
5. `pressure_residual_corr`：恢复后 R、AC、DC 与 Ut 输入特征的残余相关性。
6. `red_ir_consistency`：Red 与 IR 的峰谷配对一致性。

伪真值相关 NRMSE 可以继续输出，但只作为参考列，不作为主排序依据。

## 6. 时域波形评价指标

为了避免恢复后波形看似平滑但破坏搏动结构，本阶段引入时域指标：

1. 峰间期稳定性：按压段 peak-to-peak interval 的 CV、MAD 和最大相邻跳变。
2. 峰定位偏移：按压段峰位置相对邻近静息模板或局部趋势的偏移。
3. 伪峰/漏峰计数：恢复后新增异常短间隔峰、漏检峰或边界双肩峰。
4. 峰显著性稳定性：peak prominence 与局部 AC 包络是否出现异常突变。
5. 边界 AC 跳变：按压前后外边界附近，以局部稳定静息 AC 幅值归一化，而不是除以 ADC 大基线。

峰定位不直接使用 recovered 原波形裸数据。推荐流程是：先对 IR 或 Red/IR 合成检测信号进行带通和平滑，再找主峰；以 IR 作为主峰检测通道，Red 只在 IR 峰/谷附近的局部窗口内配对提取，避免恢复产生的小毛刺参与 SpO2 计算。

## 7. 数据流

Phase 2 实验数据流如下：

```text
raw csv
  -> 读取 Red/IR/Ut1/Ut2
  -> 预处理与低通 Ut
  -> 构造输入组：ut1_only / ut2_only / common_only / difference_only / common_difference / raw_pair
  -> 事件检测与事件+缓冲区校正窗口
  -> 候选恢复算法
  -> 峰谷检测与 AC/DC 提取
  -> R 与 SpO2 计算
  -> 时域指标、边界指标、SpO2 指标、伪真值参考指标
  -> 输出 PNG 诊断图与指标 CSV
```

## 8. 验收标准

Phase 2 一轮实验完成后，需要产出：

1. 每个候选算法和输入组的指标表，主排序依据为 SpO2 稳定性、时域峰结构稳定性和边界连续性。
2. 关键事件的 PNG 诊断图，至少包含 observed、recovered、pseudo reference、Ut 输入、峰谷标记、R/SpO2 局部结果。
3. 对 `Ut1`、`Ut2`、`common`、`difference` 是否等效或互补的结论。
4. 对自适应滤波短事件收敛情况的结论，包括是否出现边界双肩峰、是否需要更长缓冲区或更强正则化。
5. 更新 `research/spo2_recovery/v2/docs/experiment_report.md`，说明本轮算法设计、实验过程、指标解释和下一步建议。

## 9. 非目标

本阶段不优化在线实时部署，不以最低延迟或最小计算量为目标。离线恢复效果和可解释性优先。

本阶段不引入黑盒深度学习模型。

本阶段不把伪真值 NRMSE 作为唯一或最高优先级指标。
