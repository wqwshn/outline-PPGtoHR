# Ut1 接触压力伪影白盒恢复设计

## 1. 研究目标

使用热式界面传感器的 Ut1 信号感知腕表与皮肤之间的接触压力变化，并消除压力变化
对 Red/IR PPG 波形造成的影响，尽量恢复接近静息状态下自然脉搏形态的波形，为后续
稳定计算 SpO2 提供输入。

本阶段以单次按压实验数据上的最佳离线恢复效果为最高优先级：

- 允许使用完整时间序列、零相位滤波和事件前后数据；
- 允许针对当前数据拟合参数；
- 暂不要求在线、因果或跨被试泛化；
- 算法必须是可分解、可审计的白盒信号处理方法；
- 不使用神经网络或不可解释的端到端波形映射。

本阶段的核心研究问题是：

> Ut1 能否作为接触压力状态的观测量，分别解释并校正 PPG 的慢变基线偏移和脉搏
> 振幅调制，同时避免产生伪峰或破坏 Red/IR 的生理比例？

## 2. 已知数据与现有方法诊断

输入数据为：

`research/spo2_recovery/v2/data-按压干扰实验.csv`

关键通道包括：

- `PPG_Red`、`PPG_IR`：MAX30101 18 位 ADC 码值；
- `Ut1(mV)`、`Ut2(mV)`：恒温差惠斯通电桥桥顶电压；
- 加速度和角速度：用于辅助诊断，不作为本实验的主要事件检测依据。

腕表底部的 PPG 光学传感器直接接触皮肤，两个薄膜界面热式传感器对称布置在 PPG
左右两侧。因此，Ut1 和 Ut2 测得的是 PPG 光学窗口邻近区域的局部界面热响应，而
不是 PPG 中心位置的直接压力真值。算法中将它们解释为接触压力/间隙状态的代理观测，
不直接换算为绝对压力。

对称布局提供三类具有明确空间含义的参考量：

```text
left_or_right(t) = Ut1(t) 或 Ut2(t)
common(t) = (Ut1(t) + Ut2(t)) / 2
difference(t) = (Ut1(t) - Ut2(t)) / 2
```

- 单侧量描述对应一侧的局部界面变化；
- 共模描述 PPG 两侧一致的整体压紧或松开；
- 差模描述腕表倾斜、受力偏心或左右接触不对称。

当前数据包含约 57.6 s、100 Hz 采样的连续记录和 7 次按压/松开事件。初步量化显示：

- Ut1 可清晰识别 7 次按压，事件约位于 14.7、20.8、26.1、31.6、37.6、44.5、
  51.6 s 附近；
- 每次按压均引起明显 PPG DC 偏移，但偏移幅度并不与 Ut1 呈固定比例；
- PPG 的 AC 包络在不同事件中可能增大、减小或近似不变；
- 松开后常存在残余基线偏移，表明系统具有动态响应和迟滞；
- 因此，压力伪影不是单一的加性噪声。

现有 v1 自适应滤波方法存在两个关键问题：

1. 主要依赖加速度识别运动段，而本次静息按压实验的加速度变化很小，导致新数据上
   未识别到任何恢复区间；
2. LMS/AS-LMS 将 Ut 相关分量整体作为加性噪声消除，会产生大量尖峰和伪搏动。
   在既有实验中，恢复后有效心搏数表面上增加，但运动段 SpO2 从约 96.8% 降至约
   80%，说明新增峰值主要是算法伪影。

因此，本方案不再将 Ut1 直接视为“从 PPG 中减去的噪声”，而将其视为压力状态观测。

## 3. 信号模型

对每个波长独立建模：

```text
x_lambda(t) = B_lambda(t) + G_lambda(t) * p_lambda(t) + epsilon_lambda(t)
```

其中：

- `x_lambda(t)`：观测到的 Red 或 IR PPG；
- `B_lambda(t)`：受接触压力影响的慢变 DC 基线；
- `G_lambda(t)`：压力引起的脉搏 AC 幅值增益；
- `p_lambda(t)`：希望恢复的干净脉搏波；
- `epsilon_lambda(t)`：高频噪声和未建模残差。

主任务仍以 Ut1 为核心参考。为利用已知对称布局，同时建立 Ut2、共模和差模输入的
消融对照。白盒特征包括：

```text
z(t) = [
    U1(t),
    U2(t),
    common(t),
    difference(t),
    trend terms,
    derivative terms,
    press/release state,
    finite lag terms
]
```

其中 `press/release state` 用于区分加压与松开过程，允许两条不同的响应曲线，以描述
迟滞。候选模型只能选用预先定义的小型特征组，避免把双传感器扩展为高维黑盒回归。

分别估计：

```text
B_hat_lambda(t) = f_lambda(z(t))
G_hat_lambda(t) = g_lambda(z(t))
```

恢复的归一化脉搏分量为：

```text
p_hat_lambda(t) =
    (x_lambda(t) - B_hat_lambda(t))
    / max(G_hat_lambda(t), G_min)
```

最终波形使用事件前后静息段插值得到的自然基线和自然 AC 幅值尺度重构。Red 和 IR
共享模型结构与事件边界，但参数独立拟合，防止强制两波长具有相同压力响应。

## 4. 预处理与信号分解

### 4.1 基础预处理

- 非有限值使用局部线性插值；
- 孤立 ADC 毛刺使用 Hampel 规则替换；
- Ut1 使用 5 Hz、三阶、零相位 Butterworth 低通；
- Red/IR 使用 8 Hz、三阶、零相位 Butterworth 低通；
- 所有滤波参数保存到实验配置和结果元数据。

### 4.2 DC 与 AC 分解

首轮使用互补滤波分解：

- DC：低于约 0.35 Hz 的慢变分量；
- AC：约 0.5-5 Hz 的脉搏分量；
- AC 包络：对 AC 分量取 Hilbert 包络后再低通。

截止频率不固定为唯一正确值。实验中在不泄漏按压伪影到脉搏频带的前提下，对少量
候选截止频率进行敏感性分析。

## 5. Ut1 事件识别与阶段划分

默认事件检测由 Ut1 主导，不再依赖加速度阈值。Ut2 和共模用于边界一致性检查：
若两侧响应方向一致，则提高事件可信度；若差模显著，则将事件标记为偏心受力，供
模型拟合和逐事件评价分层使用。

1. 从 Ut1 中提取慢趋势和去趋势压力响应；
2. 使用稳健基线、中位数绝对偏差和持续时间约束检测候选事件；
3. 合并短间隔片段，删除过短脉冲；
4. 根据 Ut1 的导数和局部极值确定事件阶段。

每次事件划分为：

- `pre_rest`：按压前静息；
- `loading`：加压；
- `hold`：压力维持或缓慢变化；
- `release`：松开；
- `post_rest`：松开后恢复静息。

事件表至少保存：

```text
event_id
pre_rest_start_s
loading_start_s
hold_start_s
release_start_s
post_rest_start_s
post_rest_end_s
ut1_baseline_mv
ut1_peak_mv
ut1_delta_mv
```

算法同时输出事件检测诊断图，便于人工检查 7 次事件边界是否合理。

## 6. 伪真值构造

按压期间没有同步的干净 PPG 真值，因此使用事件前后静息心搏构造评价伪真值。

### 6.1 心搏模板

对每个事件、每个波长：

1. 在 `pre_rest` 和 `post_rest` 中检测可靠心搏；
2. 按相邻波谷切分单搏；
3. 将每搏重采样到统一相位轴；
4. 剔除形态离群搏动；
5. 使用逐相位稳健中位数建立前、后静息模板。

### 6.2 事件内插值

对前后模板的下列参数进行平滑插值：

- DC 基线；
- AC 峰峰值或稳健包络；
- 心搏周期；
- 归一化模板形态。

按照插值心搏周期将模板铺回事件区间，形成连续伪真值。

### 6.3 使用边界

伪真值仅用于：

- 模型选择；
- 参数比较；
- 评价恢复质量；
- 生成误差图。

伪真值不直接替换最终恢复输出。拟合压力响应模型时，只允许使用伪真值提取的基线、
AC 包络和低维形态约束，不使用完整逐点伪真值进行自由回归，避免自证循环。

## 7. 候选白盒算法

### 7.1 基线方法

- 原始 PPG，不恢复；
- v1 LMS；
- v1 AS-LMS。

基线方法用于证明新模型的增益，不作为默认最终方法。

### 7.2 FIR 滞后回归

使用 Ut1 及有限滞后项预测 DC 偏移：

```text
artifact_DC(t) = sum_k w_k * U(t-k)
```

权重通过带正则的最小二乘求解。该模型线性、透明，可直接展示脉冲响应，但对迟滞和
AC 增益变化的表达能力有限。

### 7.3 迟滞分段样条

根据 `dU/dt` 将样本分为加压支路和松开支路，分别使用低自由度样条拟合：

```text
U -> DC offset
U -> AC gain
```

样条结点数量保持较少，所有结点和系数写入结果。该模型可解释相同 Ut1 水平在加载和
释放阶段产生不同 PPG 响应的现象。

### 7.4 Hammerstein/Wiener 动态模型

推荐主模型采用低阶静态非线性与线性动态系统串联：

```text
Ut1 --static nonlinearity--> pressure state --FIR/IIR dynamics--> PPG effect
```

分别拟合：

- DC 偏移动态模型；
- AC 增益动态模型。

候选静态非线性限于分段线性或低阶样条，动态部分限于低阶 FIR 或稳定低阶 IIR。
模型阶数由事件级交叉验证和复杂度惩罚选择。

### 7.5 消融实验

每种有效模型至少比较：

- 仅校正 DC；
- 仅校正 AC；
- 联合校正 DC 和 AC；
- 联合校正并启用加载/释放迟滞；
- 联合校正但禁用迟滞。
- 仅 Ut1；
- 仅 Ut2；
- 仅双侧共模；
- 共模加差模。

消融结果用于判断性能改善主要来自基线恢复、振幅恢复还是迟滞建模。
双传感器消融同时判断主要伪影来自整体压紧还是偏心接触。若 Ut2、共模或差模未带来
稳定增益，最终模型保持 Ut1 单参考，不因硬件上存在两路信号而强行增加复杂度。

## 8. 模型拟合与选择

本阶段允许使用全部 7 次事件联合拟合，以优先获得当前数据上的最佳恢复效果。

同时执行留一事件验证作为诊断：

1. 每次保留一个事件不用作拟合；
2. 使用其余 6 个事件估计参数；
3. 在保留事件上计算评价指标；
4. 汇总 7 次诊断结果。

留一事件结果不作为本轮的硬性成功门槛，但用于识别明显的事件过拟合和后续泛化风险。

参数选择遵循：

- 候选数量有限；
- 模型阶数低；
- 使用显式复杂度惩罚；
- 不通过大规模黑盒超参数搜索追逐单一指标；
- 每个最终参数都必须能对应到明确的信号处理含义。

## 9. 评价体系

### 9.1 主要波形指标

- 与伪真值的 Pearson 相关系数；
- NRMSE；
- DTW 距离；
- 逐搏模板相关系数；
- DC 基线绝对误差；
- AC 峰峰值或包络相对误差。

### 9.2 心搏时序与形态

- 心搏间期误差；
- 漏搏率；
- 伪峰率；
- 峰谷顺序异常率；
- 收缩峰宽度和上升时间偏差；
- 可可靠提取的有效心搏比例。

### 9.3 SpO2 相关指标

- Red/IR 各自的 AC/DC；
- ratio-of-ratios 的事件内偏差；
- SpO2 相对前后静息参考的偏差；
- SpO2 时间序列标准差和极差；
- 超出生理合理范围的窗口比例。

### 9.4 静息段无损伤

将最终模型应用到未按压静息段，检查：

- 波形 NRMSE；
- 心搏峰时刻变化；
- AC/DC 变化；
- ratio-of-ratios 变化；
- SpO2 变化。

静息段不应因模型校正出现新的波形变化。

### 9.5 Ut1 残余相关性

报告恢复波形的 DC、AC 包络与 Ut1 的残余相关性，但不把“相关性最低”直接等同于
“恢复最好”。如果降低相关性的同时破坏脉搏形态，该模型仍应淘汰。

## 10. 硬性否决规则与综合评分

模型出现以下任一情况时直接淘汰：

- 伪峰率明显高于原始 PPG 或伪真值；
- 静息段产生可见损伤；
- AC 增益为非正值或出现数值爆炸；
- Red/IR ratio-of-ratios 明显偏离前后静息范围；
- SpO2 出现持续性严重下偏或异常跳变；
- 事件边界处出现明显不连续；
- 输出主要由伪真值模板替换而非 Ut1 压力模型解释。

通过否决规则的模型按以下优先级排序：

1. 波形形态与伪真值一致性；
2. 心搏时序准确性和低伪峰率；
3. DC、AC 恢复误差；
4. Red/IR 比例和 SpO2 稳定性；
5. 模型简单性和参数可解释性；
6. 留一事件诊断表现。

综合评分必须保留各子指标，不只输出单个总分。
