# v2-python GUI 屏气实验血氧评估模式设计

日期：2026-06-10

## 1. 背景与目标

当前 v2 血氧计算页面主要面向 Red/IR PPG 与 Ut1/Ut2 参考信号结合的抗伪影实验。屏气实验的目标不同：实验过程为静息、屏气约 35 s、再静息，核心任务是基于 Red/IR 原始 PPG 计算血氧饱和度，并与指压式脉搏血氧仪真值对齐评估。

屏气实验不涉及运动伪影和接触压力伪影恢复，因此本模式不使用 Ut1、Ut2、ACC、CF 等参考通道，不输出 `spo2_ut1` 或 `spo2_ut2`。评价对象必须是 Red/IR 血氧计算链路本身，以及用于模拟商业脉搏血氧仪输出规律的可复用后处理参数。

## 2. 输入与命名规则

GUI 在 v2 血氧计算页面增加一个勾选项：`屏气实验`。勾选后，用户只需选择传感器 CSV。

真值文件按传感器数据文件 stem 自动匹配：

```text
Spo2_HB1.csv      -> Spo2_HB1_ref.csv
Spo2_HB1.csv      -> Spo2_HB1_ref.xlsx
sample.csv        -> sample_ref.csv
```

读取逻辑不能只依赖后缀。当前真值文件虽然命名为 `.csv`，实际内容是 Excel 工作簿，因此需要先检查文件头；若为 ZIP/Excel 内容，使用 `pandas.read_excel`，否则使用 `pandas.read_csv`。

传感器 CSV 需包含现有 v2 原始列，屏气模式只读取：

- `Time(s)`
- `PPG_Red`
- `PPG_IR`
- `ValidFlag` 或等价有效性列

## 3. 分析范围

按任务要求默认去掉首尾各 30 s：

```text
analysis_start_s = 30.0
analysis_end_s = recording_duration_s - 30.0
```

所有误差指标只在该中间段计算。原始全长曲线可以用于绘图背景或调试，但不进入主指标。

该裁剪参数写入配置与输出 metadata，后续数据仍默认沿用同一规则。

## 4. Red/IR-only 血氧计算

屏气模式复用现有 Red/IR AC/DC 与 MAX30101 二次公式：

```text
R = (AC_red / DC_red) / (AC_ir / DC_ir)
SpO2 = a R^2 + b R + c
```

实现上应新增一个 Red/IR-only 计算入口，而不是复用带 Ut 恢复分支的完整 `solve_spo2_v2` 输出。该入口可以复用现有窗口级 AC/DC、峰谷定位、去毛刺和低通预处理函数，但输出表只包含一条计算曲线：

- `time_s`
- `spo2_raw`
- `r_median`
- `valid_beat_count`
- `reliable`

在屏气评估完成后，最终导出的评估 CSV 使用：

- `time_s`
- `spo2_calculated`
- `spo2_truth`
- `error`
- `spo2_raw`
- `device_model_lag_s`
- `device_model_smooth_s`

## 5. 脉搏血氧仪输出动态建模

指压式脉搏血氧仪通常存在内部平滑与检测延迟。屏气后血氧下降与恢复的时间位置可能相对 Red/IR 直接计算曲线滞后。因此后处理不是一次性调参，而应抽象成可复用的“设备输出动态模型”。

本阶段采用小参数、可解释的模型：

```text
raw Red/IR SpO2
  -> 有限窗口平滑
  -> 整体时间滞后/提前对齐
  -> 可选常数 bias 校正
  -> modeled SpO2
```

推荐参数范围：

- 平滑窗口：`1-15 s`
- 时间偏移：`-20 到 +20 s`
- bias：可选，默认只在训练/拟合模式中估计，外部测试时默认固定使用已学得参数

为了保证参数可复用，GUI 和底层 API 需要区分两种运行方式：

1. **拟合模式**：在当前屏气数据上搜索设备模型参数，目标函数以 MAE 为主。
2. **评估模式**：使用已保存的设备模型参数，不重新用该数据真值调参，用于后续新数据外部测试。

本次 GUI 首版可默认执行拟合模式，并把最优参数保存为 JSON；同时底层函数必须支持传入固定参数，以便后续数据复用。

## 6. 真值对齐

真值一般为 1 Hz 指压式血氧仪记录，传感器 Red/IR 为 100 Hz。对齐策略：

1. 传感器曲线按窗口中心时间得到约 1 Hz 计算血氧。
2. 真值文件若包含绝对时间戳，则转换为相对起点秒；若只有序列，则默认以 1 Hz、从传感器起点对齐。
3. 在分析范围内，将真值插值或阶梯保持到计算血氧时间点。
4. 搜索时间偏移时，只移动计算曲线的设备模型输出，不移动原始真值。

输出 metadata 必须记录：

- 真值文件路径
- 真值采样间隔估计
- 分析范围
- 对齐方式
- 是否执行参数拟合
- 最终设备模型参数

## 7. 误差指标

主指标采用参考论文常用的 MAE：

```text
MAE = mean(abs(spo2_calculated - spo2_truth))
```

MAE 表示平均血氧百分比误差。例如 MAE 为 1.8，表示平均偏差约 1.8 个百分点。

辅助指标用于解释误差来源：

- `RMSE`：对大误差更敏感，暴露屏气最低点或恢复段的尖峰误差。
- `Mean Bias`：平均有符号误差，判断整体偏高或偏低。
- `MaxAE`：最大绝对误差，检查最差时刻。
- `Nadir SpO2 Error`：最低血氧值误差，评价屏气低谷幅度。
- `Nadir Time Error`：最低点出现时间误差，评价下降和恢复时序对齐。
- `Pearson r`：趋势相关性，仅作辅助，不作为主排序依据。

输出需同时记录：

- `raw_mae`：Red/IR 直接计算、未套用设备动态模型的 MAE。
- `modeled_mae`：套用平滑与时移模型后的 MAE。

这样可以清楚区分血氧计算本身的误差和模拟指压式血氧仪输出动态后的误差。

## 8. 图像输出

屏气模式输出一张主图，参考 `research/spo2_holdbreath/ref/holdbreath.png` 的论文图风格：

- x 轴为时间，单位可用秒或分钟，默认分钟。
- y 轴为 `SpO2 (%)`。
- 真值曲线使用橙色阶梯或短横线。
- Red/IR 计算曲线使用粗紫色实线。
- 若可识别屏气区间，则以浅灰色背景带标注；首版可以根据真值下降段或最低点附近估计，也可在 metadata 中标注为自动估计。
- 图中嵌入 MAE、RMSE、bias、lag 和 smooth 的简短摘要。

根据项目绘图规则，默认导出：

- 600 dpi PNG，用于 GUI 直接查看。
- SVG 和 PDF，用于论文或报告复用。

图像生成优先复用 `skills/publication-plotting/scripts/plot_style.py` 与现有 v2 绘图风格。

## 9. GUI 与输出

v2 血氧计算页面新增：

- `屏气实验` 勾选框。
- 勾选后隐藏或禁用 Ut 参考信号相关控件，避免用户误以为该模式会使用 Ut 恢复。
- 可选显示“拟合设备动态参数”勾选项，默认开启；后续加入固定参数文件选择。

Worker 在屏气模式下输出：

- 原始 Red/IR 血氧 JSON
- 屏气评估 JSON
- 屏气评估 CSV
- 屏气评估 PNG/SVG/PDF
- 误差指标摘要

日志中明确写出：

```text
屏气模式：仅使用 PPG_Red / PPG_IR，不使用 Ut1/Ut2 恢复。
```

## 10. 测试策略

采用 TDD 实现，先写失败测试再写生产代码。

计划测试点：

1. 真值文件自动匹配 `{stem}_ref.csv`。
2. Excel 内容但 `.csv` 后缀的真值文件可正确读取。
3. 首尾 30 s 裁剪只影响误差指标范围。
4. Red/IR-only 入口不输出 `spo2_ut1`、`spo2_ut2`。
5. 设备动态模型在固定参数模式下不重新拟合真值。
6. MAE、RMSE、bias、MaxAE、最低点值误差和时间误差计算正确。
7. GUI 勾选屏气模式后构造正确配置，且禁用 Ut 参考控件。

## 11. 非目标

本阶段不处理运动伪影、不做 Ut1/Ut2 波形恢复、不训练黑盒模型。

本阶段不追求在线实时部署。平滑与时移模型用于解释并复现指压式血氧仪输出规律，首要目标是离线评估与后续跨数据复用。
