# 冻结 LYX 八场景选择器开发回代

Status: accepted

LYX 已完成联合开启上升候选谱系与受压保护目标连续可见性的八场景、二十四记录、三百物理坐标响应面缓存。两项机制在该 7200-cell 实验身份中均开启，但仍保持生产默认关闭。当前问题不是继续挖掘完整参数效应或动态 episode，而是检验同一场景的两条训练记录能否支持一个可复算的参数选择，使第三条记录的完整有效评价时间轴心率结果合格。

本阶段预留修正版合同 `lyx_eight_scene_joint_selector_development_gates_v2`，不恢复 evaluator 绑定有误的 v1 草案，也不追溯修改 `physical4d_corrected_development_gates_v2`。八场景主资格统一使用固定 5 秒下的 G1-I、G2、G3、G4、G5 和 G7。旧 G6 上升 episode 门、强持平诊断以及上升/下降动态诊断均不进入 7200-cell 资格、公共解、排序、留出合格或主裁决；缺少合格 episode 只表示动态门不适用，不能推出心率预测不准确。

多人路径已经冻结的 `gate_aware_full_mae_time_bias_v3` 作为独立的求解后评价敏感性保留：每折必须先用固定 5 秒主合同冻结 top-1 并揭盲，随后才能对该留出记录的唯一冻结轨迹比较 4.0/4.5/5.0/5.5/6.0 秒。v3 条件上升安全门对所有场景运行，但候选与基线均无合格上升子段时记为不适用；它不是旧 G6。敏感性不得回流参数资格、公共解、训练排名、折通过或 24/24 裁决，也不得让 7200 个坐标分别选择偏置；没有 top-1 的折不进行微调。

每个场景先计算三条记录的共同合格集，回答冻结 300 坐标空间内是否存在公共解。该集合只作 oracle 可达性和揭盲后诊断，不能进入选择器候选池。公共集合为空时记为 `SPACE_UNREACHABLE`；两条训练记录没有共同合格坐标时记为 `TRAINING_SET_UNREACHABLE`，不得选择最小坏值。两种失败都不终止其他场景，也不移出最终分母；仍完成八场景、二十四折和近失审阅。

每折只读取两条训练记录。概念候选池始终是完整 300 坐标，实际排序域是两条训练记录同时合格的坐标。冻结排序和 top-1 回执后才揭示留出记录。主规则固定为 `historical_platform_control`：先保留最坏训练 MAE 距本折最优不超过 0.5 BPM 的近优池，再按单轴相邻一档的支持邻居比例、支持邻居数、悬崖数、训练平均 MAE 和物理坐标顺序排序。`minimax_mae`、`maximin_gate_margin` 和 `agreement_then_minimax` 只作诊断，揭盲后不得替换主规则。

严格成功要求八个场景分别 3/3，合计 24/24；场景平均或总平均不能补偿任一失败折。原四场景、增加四场景和完整八场景分别报告。由于所有记录均已参与算法与规则讨论，本实验只证明开发回代与读取隔离，不构成独立泛化确认。

分析只读取既有 7200-cell 报告和二十四条历史独立 BO Final baseline，不运行 solver 或 BO。完整输出时间轴负责结构身份检查；施加统一 `time_bias=5 s` 后，准确性指标只在候选、基线与参考共同存在的完整有效评价时间轴上计算，参考范围外的输出窗口不得误判为参考缺失。只有源码/算法身份、输入、缓存、合同绑定、确定性或读取隔离失效才使整体实验无效。结果有效但未达到 24/24 时，应保留不可达、选择失败和近失证据，而不是修改合同或自动扩充规则。

旧 3600 缓存按依赖分阶段释放。新的自含 7200 行表、冻结回执、折结果、独立验证和报告依赖清单完成后，如果清单确认不再直接读取旧 base 3600 报告，可删除其 solver 报告缓存；摘要和验证证据继续由证据分支保存。rise-on 3600 含直接机制与风险证据，不整包删除，只在另行生成引用/风险保留清单后做定向裁剪。

## 执行结果

正式 v2 实验已完成并通过独立复算：7200/7200 cell 身份与六门有效，主规则原四场景 10/12、新增四场景 0/12、完整八场景 10/24，裁决为 `EIGHT_SCENE_SELECTOR_DEVELOPMENT_REPLAY_NOT_CLOSED`。Jianpan、Quanji、Run 达到 3/3；Kaihe 为 1/3；Bobi、Tiaosheng、Woli、Xiezi 的三记录公共集合均为空。该结果不追溯修改合同或用诊断规则替换主规则。

冻结 top-1 后的 v3 敏感性完成 18/24 折，16 折 MAE 改善、2 折不变、0 折退化，但 11 折存在五个偏置均未通过原 v3 门槛的风险；敏感性未回流固定 5 秒主裁决。solver 与 BO 新调用均为 0。
