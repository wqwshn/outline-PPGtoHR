# 允许 LYX 后验参考路线评估独立选择 Physical4D 坐标

## 背景

ADR 0008 将 HF 固定为论文算法主线，并要求 ACC 仅以冻结 HF 参数作下游对照。该约束保护了原始研究叙事，但也留下一个无法由配对重放回答的问题：如果 ACC 本来偏好不同的自适应物理参数，那么沿用 HF 坐标可能低估 ACC；同理，HF 与 ACC 的联合参考池是否互补，也不能只在 HF 坐标上判断。

当前 LYX 跨佩戴阶段已经以 `EIGHT_SCENE_24_OF_24_POSTHOC_CURATED` 收尾。它属于单个体、后验获选开发面板，不是独立验证；本决策不得重新打开原 24/24 的算法、面板、六门、HF 选择器或裁决。

## 决策

建立新的后验研究身份，在同一 24 条获选记录、同一场景内三折结构、同一固定五秒评价时间线和同一 300 点 Physical4D 空间中比较三条参考路线：

- HF：完全复用当前冻结的 24 个三折坐标与固定五秒结果，不以新规则重选；
- ACC：只用每折两条训练记录，在全部 300 坐标上依次最小化最坏 MAE、平均 MAE和冻结坐标顺序；
- HF+ACC 联合参考池：采用 `reference_groups_order=("HF", "ACC")` 的相关性排序级联，并使用与 ACC 相同的训练侧 minimax 字典序独立选参。

每折形成一张 `3×3 参考路线—坐标来源交叉评价矩阵`。对角线是正式主结果；非对角线只解释参数迁移，不产生新的择优算法。ACC 与 HF+ACC 不使用 HF 六门，也没有性能“无效”状态；所有有限 MAE 均如实进入结果。只有缺失、损坏或非数值输出属于技术未完成，按完全相同身份补算。

完整求解只在内存中短暂存在。正式持久化采用紧凑响应账本：导入 7,200 个既有 HF 标量 cell，新计算 ACC 与 HF+ACC 共 14,400 个 cell，只保存坐标、路线、固定五秒 MAE、冻结窗口身份、输入/算法身份和技术回执。普通 cell 不保存完整 solver report；获选或风险 cell 如需时序证据再定向复算。

## 报告边界

主要效应量是 24 条留出记录的配对 MAE 差值均值；同时报告中位数、原始点和场景均值方向 `x/8`，不把记录或窗口当作独立受试者计算 p 值。预先指定三组差值：`ACC−HF`、`HF−HF+ACC`、`ACC−HF+ACC`。逐记录 oracle `min(HF, ACC)−HF+ACC` 只可作为明确标注的描述性敏感性结果，不进入主图或主结论。

主图固定为一个不对称三面板复合图：对角线性能原始点、三组配对差值、以及相对本路线对角线的 3×3 坐标迁移代价。完整绝对 3×3 数值和参数选择频率进入紧凑表，不重复画图。

## 后果

- 这是对 ADR 0008 的窄范围研究例外，不改变 HF 主线、原配对 ACC 基线或生产配置。
- 结果无论支持、削弱还是反转 HF 优势，都使用同一预冻结表图如实汇报。
- 实验在新的干净工作树执行；旧 LYX 证据只读、按提交和哈希导入。
- 全部账本、逐记录指标、图表和运行回执只在本地 `data/experiments/` 保存，不加入 Git 或远端历史。
- Stage 1 完成 14,400/14,400 新 cell、48 个新坐标选择、24 张 3×3 矩阵和固定报告后停止，不自动进入时延优化、门槛设计、算法修改、跨个体或新搜索空间研究。
