# ADR 0017：将窗口间权重状态纳入 NLMS 机制实验

## 状态

已接受

## 背景

当前 HF 自适应滤波研究不仅需要确定阶数、步长、正则化和时延机制，还需要回答权重是否应在相邻心率窗口之间保留。独立窗口有利于隔离单窗口内 HF 参考信号的贡献，但每次都从零开始；连续权重更接近未来在线部署，可能缩短稳定运动中的收敛时间，也可能在运动阶段切换或参考质量下降时携带过时状态。

心率窗口存在重叠。如果在保留权重后再次用完整重叠窗口更新，窗口之间重复的样本会被多次学习。这既不代表独立窗口，也不代表真实连续数据流，并会混淆权重继承带来的收益。

## 决策

将权重状态作为 NLMS 机制 DOE 的正式实验因素。

第一阶段进行完整配对比较：

- W0 独立窗口权重：每个 8 秒窗口将权重清零，并处理完整窗口。
- W1 连续流权重：首个 8 秒窗口用于初始化；此后窗口每推进 2 秒，只用新到达的 2 秒数据更新一次，同时保留上一时刻权重。

禁止采用“保留上一窗口权重，再重新训练完整 8 秒重叠窗口”的实现，因为这会重复利用其中 6 秒数据。

带质量或运动阶段事件的衰减、冻结和重置策略记为 W2 门控连续权重。W2 不进入第一阶段的完整网格，而在阶数、固定步长和 W0/W1 的稳定参数平台形成后，作为稳定性机制进入第二阶段。

W2 状态机必须满足因果证据边界：允许使用当前及历史的双侧 HF、PPG、NLMS 残差、预测伪影、权重范数与变化率、数据中断和传感器质量，并保留统一的 200 ms HF 前视；禁止使用人工标注的运动开始或结束时间、参考心率、超出固定前视的未来状态，以及由整条记录结果反推的切换时刻。运动标签只用于分段评价和作图；完整记录零相位滤波仍可作为本轮离线上游，但 W2 本身必须能在预处理信号流上因果运行。

W2 采用分级动作而非单一清零规则：正常更新用于 HF 有效且映射可信时；冻结通过令更新步长为零暂时保留已学映射；泄漏按物理半衰期平滑遗忘持续失效的旧状态；完全重置只用于数据中断、权重发散或传感器状态突变等强证据事件。

W2 按 F（冻结）、FL（冻结加泄漏）、FLR（完整加入重置）做嵌套消融，并通过进入/退出滞回与最短驻留抑制状态抖动。讨论中的 0.5、1、2、4 秒等持续时间只作为首轮候选，应结合状态轨迹、频谱收益和误触发失败模式进一步评估，不作为预先锁死的最终阈值。

## 结果

### 正面影响

- 可以定量回答独立窗口与在线连续学习各自的收益和风险。
- W1 的实验语义与未来流式部署一致，每个输入样本只更新一次。
- 避免把重叠样本重复训练造成的表面收益误认为权重继承收益。
- W2 可以针对阶段切换后的历史状态污染做进一步闭环优化。

### 代价与风险

- W0 与 W1 的更新预算和冷启动条件不同，需要同时报告早期窗口与稳定阶段结果。
- 连续权重使相邻窗口不再统计独立，后续推断与可视化必须按完整记录和事件段处理。
- W1 可能在静止到运动、运动类型切换或 HF 质量下降后保留错误权重，因此需要记录权重范数、变化率和恢复时间。

## 验证要求

- 第一阶段在两个哨兵样本上对 W0/W1 做相同阶数与固定步长网格的配对比较。
- 权重状态收益采用双口径报告：主分析在每个相同记忆长度、步长和正则化条件下计算 W1 相对 W0 的配对效应，以隔离权重连续本身的作用；次分析允许 W0/W1 分别从各自稳定参数平台选择配置，比较合理调参后的最佳可达性能。两者不得合并成一个含义模糊的“跨窗口收益”。
- 除既定频谱证据和下游心率指标外，报告冷启动收敛时间、稳定运动收益、阶段切换后的恢复时间以及权重状态轨迹。
- 从稳定参数平台选择候选后，再研究 W2 的衰减、冻结和事件触发重置机制。
- 冻结候选方案后，在 CGX 24 个样本上进行扩大回归，确认收益不是由单一记录的状态连续性偶然造成。
