# Handgrip 使用折内性能盲训练构成

D24 Handgrip 的十五条记录继续构成六折 LOSO 的固定评价账本，但每折训练核心改由五名训练受试者的无参考心率 HF、ACC、PPG 信号独立形成：特征尺度、信号响应类型和代表记录均不得读取第六名受试者的原始信号或结果，训练核心与 HF 原六门坐标、ACC 独立坐标全部封存后才评价该受试者的全部记录。选择折内构成而不是先对十五条信号全局分型，是为了避免无标签测试分布参与训练数据选择；代价是六折可能得到不同训练核心，且当前结果因同批记录已用于诊断和能力枚举，只能作为回顾性开发证据。

每折的原始信号模式由五名训练受试者的记录共同形成，使同一模式在不同受试者之间具有可比较含义；每名受试者在其出现的每种模式中最多提供一条代表记录。模式不进入 Physical4D 坐标资格或排序，参数仍由原六门 HF 选择器与独立 ACC 选择器从冻结训练核心中选出，因此实验改变的是选参输入的数据构成，而不是选参规则本身。

共同模式必须在记录时间区块重采样中稳定复现；不稳定时退回更少模式。由此形成的同一训练核心同时交给 HF 与 ACC，允许两条路线独立选择不同坐标，但不允许通过路线专属训练名单改变比较分母。

同一受试者在同一稳定共同模式内存在多条记录时，只保留距离共同模式中心最近的一条，完全并列按记录 ID 破除；有效罕见记录全部保留。训练核心不设置额外的每人或总记录数上限，避免为了接近结果揭示的某个核心规模而反向删除真实模式。

时间稳定性主方案把每条约三分钟记录等分为四个连续块并做四次留一块重算，固定 30 秒六分块只作预设敏感性，时间块不充当独立训练记录。极短无效采样缺口在滤波前局部插值、特征汇总时按 ValidFlag 屏蔽并保留计数，不删除记录或整块。运动后 HF 恢复从整条记录的 ACC 运动事件计算，观察上限固定为 30 秒，未恢复项保留右删失身份；60 秒因所有记录均缺少统一尾段而不进入正式特征合同。

四等分留一重算是唯一主构成；30 秒六分块无论结果更好或更差都只作敏感性，不能事后替换主规则。冻结规则另在 LYX 跨佩戴开发数据的 Handgrip 场景原样运行，只检查信号模式和 HF/ACC 参数变化方向，不按该结果修改规则、不扩展到其他场景，也不声称独立验证。

正式模式距离由六类机理信息等权组成：HF 界面基线、ACC 颤动、HF 相对 ACC 的 PPG 伪影响应、运动后 HF 恢复、伪影持续性/频带范围和双 HF 一致性。同类多个数值先合成为一份类内距离，运动后恢复的截断时间与右删失身份也只共同贡献一类权重；不使用 PCA、结果驱动权重或原始特征列等权。

六类各只保留一至两个预注册数值，不建立候选特征库。分组采用训练折内六类等权预计算距离、平均链接和固定记录顺序；分别检查两类与三类，并以完整版本加四次留一时间块的五个 silhouette 和十对 ARI 裁决。候选必须满足 silhouette 全部大于 0 且中位数至少 0.25、ARI 中位数至少 0.80 且最小值至少 0.50；两个候选均通过时优先 silhouette 中位数更高者、完全并列取较少类别，均不通过时保留全部训练记录。

六折结束后可以使用全部六名开发受试者按同一冻结规则形成未来应用的最终训练核心，但它不回流 LOSO 成绩，也不增加泛化证据。第一阶段只使用 D24 当前十五条记录；只有冻结规则无法改善 HF 时，第二阶段才按原规则把历史删除的三条有效 Handgrip 记录加入训练候选池，不能依据 MAE 从三条中择优。
