# 在读取任何留出结果前冻结全部 LOSO 选择

Status: accepted

筛选面板场景内六折必须先完成全部四十八折的训练侧选择，并为每折保存五名训练受试者、训练共同合格集、排序输入、唯一 top-1 或无共同候选状态及完整哈希；只有全部选择和读取隔离审计通过后，才允许统一读取留出分区并计算固定五秒六门、失败归因、逐记录时延微调和 ACC 配对结果。逐折选择后立即揭盲虽然更便于调试，但会让早期失败影响后续折，破坏同一冻结规则的跨个体评估。

揭盲后提出的任何选择器、阈值或候选资格变化都必须进入新的开发实验，不能原位覆盖本次 LOSO，也不能借已揭盲折修改尚未评估的折。正式可视化除状态矩阵和柱状图外，还保留八张场景六折时序证据页；失败 top-1 完整展示，无 top-1 面板明确缺失且不使用替代坐标。
