# 冻结共同 G1-I 合格历史基线

跳绳面板首次冻结引用的 20260705 历史 Lite 报告在三条新增记录上存在静息窗自适应阶段，导致完整 G1-I 失败；该问题在 900 项响应面完成后、任何门指标物化和面板揭示前发现。修订阶段只检查十八份既有报告的身份门，不读取候选性能；选择三条记录共同通过、且不是 HLE20 专项变体的 `20260701_trace_rescue_raw_bandpass_full_LMS+H` 批次作为兼容基线，并要求 preflight 直接验证独立基线 G1-I。由于响应面缓存身份不包含兼容基线，900 项结果可以原样复用，但所有 G2–G4 指标必须从修订后基线重新物化；原始无效冻结和修订理由都必须保留。
