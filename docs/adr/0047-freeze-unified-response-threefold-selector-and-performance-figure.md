# 冻结统一响应面三折主选择器与最终性能图

Status: accepted

## 背景

`identity_blind_unified_rescue_v1` 的 LYX 八场景完整 Physical4D 响应面已经冻结并独立验证，二十四条记录、三百个坐标共 7200 个 solver cell 全部成功。八个场景的三记录公共合格集均非空，但公共解存在只能证明空间可达，不能证明选择器仅凭两条训练记录就能选中留出可用坐标。

旧响应面揭盲后形成的 `evidence_guarded_platform_v1` 已修正历史平台规则在 Kaihe 的候选扩张回退。该规则早于新统一响应面冻结，且只读取六门训练共同合格集、训练 MAE 与物理邻域，因此可以在绑定新响应面的新实验身份中接受一次先冻结后揭盲的正式开发回代检验。

现有三折验收图以折矩阵和逐记录曲线为主，缺少一个无论通过率如何都展示实际最终 top-1 性能的统一场景汇总图。用户要求把这类图沉淀为以后完整三折评估的主要验收结果。

## 决定

### 主选择器与主裁决

- 新三折实验的主选择器固定为 `evidence_guarded_platform_v1`；
- 每折只读取同场景另外两条训练记录的完整 300 坐标分区，冻结唯一 top-1 后才揭盲留出分区；
- `historical_platform_control`、`minimax_mae`、`maximin_gate_margin` 与 `agreement_then_minimax` 只作诊断，揭盲后不得替换主规则；
- 固定 5 秒下的 G1-I、G2、G3、G4、G5、G7 继续决定 cell 资格、训练候选域、留出合格和 `24/24` 主裁决；旧 G6、v3 与 ACC 对照均不得改变通过率。

### HF 最终评价与 ACC 配对重放

每折主规则 top-1 冻结并揭盲后，对唯一 HF 轨迹运行 `gate_aware_full_mae_time_bias_v3`，从 `4.0/4.5/5.0/5.5/6.0 s` 中得到逐记录最终评价偏置。固定 5 秒与 v3 结果都进入逐折结果表；v3 不回流坐标、资格或折标签。

ACC 对照只在已经冻结的二十四个 top-1 上运行。它复用 HF 的记录、Physical4D 坐标、统一救援机制、平滑参数及 HF-v3 已选评价偏置，唯一变化是把自适应滤波参考组合由 `reference_groups_order=("HF",)` 改为 `reference_groups_order=("ACC",)`。ACC 不运行独立 v3，不建立 ACC 响应面，不参与选择器或主裁决。该边界使对照回答“同一最终参数只更换自适应参考信号后，实际 MAE 如何变化”。

### 强制最终性能图

完整三折实验必须生成一张八场景横向分组柱状图，即使部分场景不是 `3/3`：

- 每场景使用主选择器实际冻结的三个留出 top-1；合法但失败的 top-1 必须保留，禁止改画留出 oracle；
- HF 柱展示 HF-v3 最终 MAE，ACC 柱展示在同一 HF-v3 偏置下的 ACC 重放 MAE；
- 柱高为三折均值，误差棒为样本标准差，并叠加三个折点；
- HF 柱固定在 ACC 柱上方；场景按 HF-v3 三折均值从小到大、自上而下排序，完全并列时按冻结场景名排序；
- 图中不使用总标题、通过率文字或解释性注释，只保留场景、刻度、单位和图例等必要文字；
- Python 是唯一绘图后端，强制交付 600 dpi PNG，并同时交付 SVG、PDF、逐折源数据 CSV、figure manifest 和视觉 QA。

该图展示最终实际性能分布，不承担门槛裁决。精确的固定 5 秒、HF-v3、ACC 固定 5 秒及 ACC 在 HF-v3 偏置下的逐折结果保存在表格中。

## 后果

本轮需要只读复用新 7200 HF 响应面并执行二十四次 ACC top-1 重放；不重新运行 HF 7200 solver，不运行 BO，也不删除原始缓存。实验方案和输出根必须使用新身份，不能覆盖 `lyx_eight_scene_joint_selector_threefold_20260819` 的旧结果。

无论最终为 `24/24` 还是存在 `SELECTION_MISS`，只要主选择器产生合法 top-1，就必须形成完整性能图。图中的低均值不能把固定 5 秒失败折改判为通过，也不能把开发回代宣称为独立泛化证据。
