# 将 `p25-short-low` 修订限制为第一排序参考级

Status: accepted

## Context

LYX `p25-short-low` 在修正量纲后的频谱复验中为 10/12 通过，剩余两条记录
只失败于心率频带能量占比门。随后冻结的滤波机制分解在同一批 12 条开发记录上
比较了单级与双级自适应路径：

- 第一参考级单独运行：12/12 通过；
- 第二参考级单独运行：12/12 通过；
- 按既有排序串联两个参考级：10/12 通过；
- 反向串联两个参考级：10/12 通过。

两个串联方向均失败于同一组记录。零更新双级控制为 12/12 通过，因此当前局部
失效来自两个自适应更新的串行组合，而不是双级数据流本身。两个单级路径都通过，
所以证据不能证明第一参考级在生理或统计意义上优于第二参考级。

随后执行的 rank-1 最小修订诊断把求解器和公共频谱审计入口都限制为一个参考级。
12 条记录逐值复现机制分解中的完整 `rank1_only_adaptive` 频谱证据，12/12 通过
全部冻结门槛；原串联路径的两条失败记录均转为通过，且没有新增失败。

## Decision

- 在求解器配置中增加 `adaptive_reference_stage_limit`。
- 默认值为 `None`，表示执行全部既有排序参考级，并保持旧行为与旧 trace 结构。
- `p25-short-low-rank1-v1` 固定使用
  `adaptive_reference_stage_limit=1`，只执行按既有绝对相关系数规则排序后的第一
  参考级。
- 正整数表示最多执行排序后的前 N 级；非正整数和非整数失败关闭。
- 本轮只批准 N=1。该字段不是 BO、网格搜索或逐样本选择参数。
- `penalty_ref` 仍绑定第一排序参考，其他
  `fs_target=25 Hz`、物理记忆长度 `40 ms`、实际 taps `M=1`、
  nominal `mu=0.008`、最小 `mu=1e-6`、HF 参考组、窗口规则和频谱门槛均不变。
- 该修订先停在 `awaiting_stage_r_replan_human_review`；不得自动运行 Stage R、
  Stage F、恢复/惩罚候选提名或独立 BO。

## Considered options

- 保留两级并交换顺序：拒绝。反向串联仍在同两条记录上失败。
- 固定选择第二参考级：暂不采用。它在当前面板上同样 12/12 通过，但会改变既有
  第一排序参考约定，代码与行为解释不如保留第一参考级最小。
- 将级数 N 暴露给 BO：拒绝。本次证据定位的是串联机制问题，不需要把结构修订
  重新扩张为搜索维度。
- 直接从机制分解进入 Stage R：拒绝。先要求生产配置入口逐值复现机制通道，避免
  把实验支路与真实求解器控制流混为同一证据。

## Consequences

- 生产求解器能够表达经验证的单级参考路径，同时默认调用者保持旧的全级联行为。
- 12/12 逐值复现证明修订实现与机制通道一致，但不证明 MAE、L10、L20、恢复或
  惩罚表现改善；这些仍需新的 Stage R 提案和身份。
- 当前证据仍是 `development_reuse_pilot`：四个场景全部来自 LYX，不能外推为
  未见场景、跨个体或算法级留出泛化。
- 后续主要比较基线仍是每个样本的独立 BO lite 结果；`TraceRescue` 仅作为历史
  探索背景。
