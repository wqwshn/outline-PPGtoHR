# 采用分阶段 DOE 研究 NLMS 参数机制

双侧 HF 多输入 NLMS 依次研究阶数与固定步长响应面、正则化和时延等稳定性机制、信号驱动变步长，以及冻结候选在 CGX 24 样本上的扩展表现。第一阶段所有阶数条件统一采用 200 ms 固定 HF 前视，物理记忆长度只改变向历史方向的覆盖，避免把阶数收益与更大的时间对齐范围混为一谈；权重状态则完整配对比较独立窗口与只学习新到达数据的连续流。两种权重状态共享按时间顺序生成的逐路 HF 因果运行归一化输入：首个 8 秒窗口用于初始化均值和 RMS，随后以 30 秒时间常数更新；每个新样本先使用上一时刻统计量归一化，再更新统计量，且第一阶段不做幅值裁剪。W0 只重置滤波权重而不重置上游归一化状态，从而不把归一化状态继承混入权重继承收益；PPG 端继续使用现有完整记录零相位带通和全记录 z-score，避免运行幅值压缩成为额外的伪影抑制机制，在线 PPG 归一化留作后续部署兼容性消融。第一阶段固定使用原始双侧 HF 输入且不依据 PPG 相关性翻转通道；第二阶段再与固定正交的共模/差模表示比较，禁止把 raw、common、difference 同时输入形成线性冗余。第一阶段使用相对正则化 `epsilon = 0.01P`，其中 P 为双侧 HF 输入向量总维数，避免固定绝对保护项随阶数产生不同相对强度；正则化强度扫描留到第二阶段。第一阶段不使用权重泄漏；第二阶段在稳定参数平台上以物理半衰期而不是逐采样系数比较 `infinity, 60, 20, 10, 5, 2 s`，并保留 W0/W1 配对以观察连续权重在稳定收益与阶段切换恢复之间的权衡。候选采用双哨兵非对称准入：`woli3_CGX_0710` 必须通过三维频谱证据且运动段 AAE 改善，`jianpan1_CGX_0710` 则作为硬性防退化约束，运动段 AAE 最多增加 1 BPM、5 BPM 命中率最多下降 0.05、E10 比例最多增加 0.05，且 E20 比例不得增加；不得通过两条记录求平均掩盖任一侧失败。稳定参数平台最低要求在某一权重状态的记忆长度乘步长响应面上包含一个完整通过的相邻二乘二网格，不接受孤立点或单轴细线；每个平台保留性能、区域中心和低计算量三个代表进入下一阶段，若没有平台则先诊断或调整网格而不降低验收门槛。每阶段只传递形成稳健参数平台并通过两级验收的候选，BO 仅用于训练共享参数或拟合上限复核，不用一次性黑盒搜索替代阶数、步长及其交互的机制解释。

第一阶段先运行既定粗网格，之后最多允许一次规则化细化：内部平台周围插入相邻记忆长度的中间阶数和相邻步长的几何中点；平台接触边界时只向该方向扩展一级，步长保持在 `0 < mu < 2`，历史记忆上限最多由 800 ms 扩至 1200 ms；连续近通过区域可局部加密，只有混乱孤立点时停止搜索并转入机制诊断。第二轮结束后不得继续围绕两个哨兵样本自适应扩网格。

第二阶段在每个稳定平台代表上运行稳定性全因子：相对正则化系数 `rho in {1e-4, 1e-3, 1e-2, 1e-1}`、权重半衰期 `{infinity, 60, 20, 10, 5, 2 s}` 与通道表示 `{原始双侧, 共模/差模}` 完整交叉，共 48 种配置；记忆长度和固定步长保持为该平台代表取值，W0/W1 继续配对。该设计用于识别输入条件、低能量更新保护和历史状态遗忘之间的交互，不采用逐因素最优拼接。

第三阶段先在胜出的稳定配置上比较固定步长与信号驱动变步长，仅研究正常更新状态下学习速率如何连续变化；第四阶段才把 W2 的冻结、泄漏和重置加入胜出的更新律。该顺序用于分离连续步长自适应收益与离散权重状态管理收益。

第三阶段候选固定为五组：V0 为第二阶段胜出的固定步长 NLMS；V1 为 Kwong--Johnston 型误差能量 VSS；V2 为 Aboulnasr--Mayyas 型误差自相关稳健 VSS；V3 为自适应分母正则化的 GNGD；V4 为本项目的 HF 证据驱动 VSS。V1--V3 构成经典方法对照，V4 是主要优化方向；所有候选共享相同记忆长度、通道表示、权重状态和下游追踪口径。

V4 使用三个归一化到零至一的因果证据：A 为短时双侧 HF 能量相对运行尺度的活动度，R 为残差中仍可由双侧 HF 解释的比例，G 为连续归一化梯度方向的一致性。完整 V4 以三者几何平均产生无可训练权重的证据量，再在线性映射到有界步长；同时运行 A、AR、ARG 三层嵌套消融，分别验证单纯活动、残余可消除性和持续更新方向的增量贡献。

V4 的步长上下界锚定第二阶段胜出的固定步长 `mu*`，比较保守 `[0.25mu*, 2mu*]`、平衡 `[0.10mu*, 4mu*]` 和宽范围 `[0.05mu*, 8mu*]` 三个包络，并统一裁剪为 `mu_min >= 0.005`、`mu_max <= 1.6`。包络仍以稳定区域和双哨兵门槛选择，不重新搜索样本专属绝对步长。

V4 的 A、R、G 三个证据共用物理时间尺度 `Tq in {0.5, 1, 2, 4 s}`，HF 活动度仍相对固定 30 秒运行尺度计算；证据平滑后直接生成步长，不再增加独立的步长平滑参数。因此 V4 主实验为三种包络乘四种时间尺度乘 A/AR/ARG 三层消融，共 36 种配置，另与 V0--V3 比较。

本 ADR 中列出的阶数、步长、正则化、半衰期、包络和时间尺度均是首轮候选与敏感性分析起点，不是最终部署参数。真正冻结的是机制分层、因果信息边界、双哨兵防退化、频谱先验收和记录级扩大验证；数值可在阶段结果揭示稳定平台、边界效应或明确失败模式后版本化修订，但必须说明证据、保持统一参数口径并重新运行相关哨兵与回归，禁止按单个样本临时调整。

最终算法按增量复杂度保留：双侧联合、VSS、W2 或其他附加机制必须在自身消融中同时提供稳定频谱证据和下游 HR 增量，并通过防退化门槛；否则回退到更简单的胜出方案。扩大实验失败应先归入参考不足、过消除、收敛不足、旧权重污染、更新不稳或追踪受限等机制桶，再做统一修改；若修改不能推动频谱与 HR 的 Pareto 前沿，或主要失败来自 HF 参考信息不足，则停止继续增加算法复杂度。
