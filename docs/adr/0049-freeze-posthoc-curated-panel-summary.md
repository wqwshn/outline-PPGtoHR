# 冻结 LYX 后验开发面板筛选与双对照择优

Status: accepted

LYX-24 的冻结 `identity_blind_unified_rescue_v1` 算法与 `sparse_domain_four_tap_fallback_v1` 选择器在固定五秒六门下为 `21/24`，剩余跳绳、握力和写字各一个失败折。2026-08-23 只新增了四条握力和三条写字记录，因此本轮即使两个场景都筛得 `3/3`，八场景也只能直接形成 `23/24`，跳绳仍为 `2/3`。

本轮将握力旧三条与新四条组成七记录候选池，枚举全部 35 个三记录面板；将写字旧三条与新三条组成六记录候选池，枚举全部 20 个面板。每个面板执行三个场景内留一记录回放：每折只读取另外两条记录的完整 300 坐标分区，用冻结选择器确定唯一 top-1，写入冻结回执后才读取留出分区。只有三个 HF top-1 都通过固定五秒 G1-I、G2、G3、G4、G5、G7 的面板才有外层择优资格。

若同场景存在多个合格面板，按以下结果前冻结顺序选择唯一开发面板：HF 固定五秒三折平均 MAE低于的 FFT/ACC 对照数量较多；最坏 HF 固定五秒 MAE较低；平均 HF 固定五秒 MAE较低；`min(FFT平均MAE-HF平均MAE, ACC平均MAE-HF平均MAE)` 较大；三记录公共合格坐标数较多；排序后的 record ID 字典序较小。三条记录等权，不按窗口数加权，不引入加权综合分或任意效果阈值。FFT 由 HF 报告同轨迹重评；ACC 只对全部合格面板实际 top-1 的去重 `记录×坐标` 请求重放，不建立 ACC 响应面。ACC 与 FFT 不参与折内坐标选择、固定六门资格或主折裁决；HF-v3 只在面板冻结后用于最终报告。

新七条记录首次补算 `7×300=2100` 个 HF solver cell；旧六条记录只读复用既有完整分区。输入、算法、坐标、门合同或缓存身份完全匹配时必须复用，禁止为形式上的“独立性”重复运行 solver。独立完整性检查从原子分区重新计算全部 55 个面板、165 个折和外层排序，并以反转输入顺序得到相同规范摘要哈希作为确定性证据。

两场景均找到面板时，合法阶段结果为 `EIGHT_SCENE_23_OF_24_TIAOSHENG_OPEN`；仅一者找到时报告实际 `22/24`，但顶层验收仍为 `CURATED_TWO_SCENE_PANEL_NOT_FOUND`；两者均未找到时维持 `21/24`。任何 300-cell 分区、竞争面板 ACC、身份绑定或独立复算不完整均为 `EXPERIMENT_INVALID`，不得跳过失败项继续排序。八场景主图继续遵守 ADR 0047 的 HF/ACC 合同，另交付获选握力/写字面板的 HF/FFT/ACC 三方法配对图。

所有结果只能称为“LYX 后验筛选的开发面板阶段总结”，claim boundary 固定为 `posthoc_curated_LYX_panel_development_summary_not_independent_validation`。按规则唯一获选不表示只有一个组合达到 `3/3`；必须保存全部组合、全部折和所有并列排序证据。
