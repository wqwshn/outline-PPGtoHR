# 多记录 LOSO 使用两类均衡后验筛选子集

完整 143 条多记录 HF/ACC 响应面和主 LOSO 结果冻结后，新的敏感性实验并列使用两类全局冻结的性能条件化子集：一类在保留全部受试者—场景格的前提下分散删除重复记录，另一类在每个场景集中删除一名真实受试者。两类主面板保留规模匹配在约 119 条，完整 143 条结果始终作为锚点；HF 继续使用原六门选择规则，ACC 继续使用原受试者等权 MAE minimax，并都在筛选后的训练数据上重新选参。

删除清单在任何新 LOSO 选参前按冻结 HF 困难顺序、场景配额和受试者配额一次性生成，禁止按折另选测试子集。格内删记录族保留六人、五训练一留出的 48 折结构；场景五受试者族改为四训练一留出的 40 折，并把八个排除受试者—场景组保留在反事实审计中。选择这一结构是为了在相近保留规模下区分分散删减与集中删减，同时避免把筛样本和改选择器混成同一个优化问题。

这些面板均是已揭盲后的开发性敏感性分析，不能替代完整主结果或解释为独立外部泛化。所有预先声明的保留率、两类困难顺序、较差结果和排除项都必须报告；若结果不理想，不得原位修改困难排序、配额或清单。
