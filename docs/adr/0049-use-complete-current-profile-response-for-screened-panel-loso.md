# 使用当前统一算法完整响应面开展筛选面板 LOSO

Status: accepted

筛选面板场景内六折将冻结 `identity_blind_unified_rescue_v1` 和完整 300 点 Physical4D 空间，对四十八条记录建立坐标对齐的响应面；精确身份匹配的 LYX 响应单元可只读复用，其他记录补齐完整坐标，不以各记录覆盖不同的 BO-120 历史求交，也不在每折重新运行 BO。虽然完整响应面的计算成本更高，但五名训练受试者的严格共同合格集、选择失配诊断和后续 Candidate Bank 都要求同一坐标在所有相关记录上可比较。

LOSO 另建版本化资格合同，继承 21/24 选择器所消费的固定 5 秒 G1-I、G2、G3、G4、G5、G7 语义，并更新为当前算法身份、四十八条筛选面板记录及五训练一留出范围；`multiperson_joint_screening_gate_v1` 仅保留在冻结 top-1 后的逐记录时延微调中，不参与训练共同合格集、坐标排序或 LOSO 通过率。

六门中的相对性能约束继续绑定四十八条记录既有且冻结的历史 Lite HF 基线清单，以保持既有工程尺度和基线独立性。完整响应面揭盲后可以从每条记录固定 5 秒下通过全部六门的坐标中，按最低 MAE 冻结一个逐记录最佳合格坐标；它只诊断共享参数距样本内能力上限的差距，不回流资格、排序或折通过裁决，也不允许先对 300 个坐标分别运行 v3 再择优。

主裁决保持逐折失败不可补偿：所选坐标只有在留出记录上通过固定 5 秒全部六门才算折通过；每场景必须六折全过，八个场景必须达到 `48/48`，才允许声明筛选面板零标定共享参数严格闭环。所有未通过结果仍完整报告并进入失败归因，不能由平均 MAE、其他场景收益或折后时延微调改判。
