# 在 7200 cell 重算前冻结无标签统一救援策略

Status: accepted for full response-surface planning; execution contract pending

## 背景

八场景 v4 评估中，Bobi、Tiaosheng、Woli、Xiezi 的三记录共同准确集均为空。评价合同已经冻结，不能因为某些曲线趋势合理或 MAE 尚可而追溯放宽公共解资格。用户允许不同场景使用不同共享物理参数，选择先完成无场景标签的统一救援、定向验证无互扰，再单独商量是否重算八场景 7200 cell。

前期四个场景专属配置原型只建立了因果可救性，不能支持“统一算法、仅共享参数不同”的主张。把原型直接全部开启也会互扰，因此本轮进一步把运行规则收敛为同一个配置 `identity_blind_unified_rescue_v1`。

## 决定

冻结一个对所有记录完全相同的算法 profile：

- 低位重捕获使用 `bounded_low_owner_harmonic_support_v1`；
- 高锁恢复使用新增的 `identity_blind_dual_high_lock_rescue_v1`，按候选所有权、连续性、频谱间距、运动邻近和历史轨迹证据互斥激活；
- 运动后最小丢失回退连续确认收紧为 3 窗，延迟原始候选启动保持 2 窗；
- 后处理动态保持开启；
- 在线规则不读取场景名、记录名或外部场景标签。

这是一次算法身份变化，不是单纯在原 4D 空间内换坐标。它包含一个新的通用高锁恢复候选，并复用、组合已有的低位重捕获和运动后交接机制；没有增加场景分类器或场景专属分支。默认配置仍不自动启用这些候选，正式实验身份必须显式冻结上述统一 profile。

不同场景仍可使用不同的场景内共享 4D 坐标。定向验证冻结如下：

| 场景 | 共享坐标 | 三记录 MAE（BPM） | 工程门 |
|---|---|---:|---:|
| Bobi | `fs050:m040:mu0012:w018` | 2.34 / 1.96 / 3.10 | 3/3 |
| Tiaosheng | `fs100:m200:mu0016:w006` | 3.97 / 3.07 / 3.22 | 3/3 |
| Woli | `fs050:m160:mu0006:w018` | 4.44 / 2.31 / 2.64 | 3/3 |
| Xiezi | `fs050:m080:mu0010:w018` | 1.52 / 3.34 / 2.21 | 3/3 |

因此，当前证据已经回答“能否在同一无标签算法下让四个新增场景各自至少存在一个公共坐标”：定向答案为能，12 条记录全部通过冻结工程门。但它只证明四个指定坐标的下界 `common_count >= 1`，不证明整个 300 点响应面的公共解数量、邻域宽度或三折选择器结果。

## 定向互扰与防退化证据

既有 Jianpan、Kaihe、Quanji、Run 各冻结一个历史公共坐标，共 12 条记录使用同一统一 profile 重放：

- 12/12 仍通过冻结工程门；
- 对 MAE、运动 MAE、L10、L20 逐项比较 v4：正向退化 0 条；
- 6 条四项完全相同，6 条至少一项改善；
- Quanji 三条均完全相同；此前 2 窗丢失确认对 Quanji2 造成的 MAE `+0.122 BPM` 已由 3 窗确认消除；
- 没有运行 BO，也没有重算 7200 cell。

这是用户要求的最高等级定向验收——已有代表公共点不退化，而不只是“至少保留一个公共点”。它仍不能替代旧四场景全部 3600 cell 的 S/A/B 公共解保护等级审计。

## 报道口径

继续保持两层结果：冻结 G1-I、G2、G3、G4、G5、G7 决定公共解和三折资格；MAE、运动 MAE、L10/L20 与完整轨迹作为报道性能层。未过严格门但趋势合理的结果可以如实报告，但不能事后放宽门槛转正；刚好过门的单点要同时报告零裕量和响应面未知风险。

本轮结果可表述为“开发集上的无标签统一算法救援实现了四个新增场景各一个定向公共解，并在四个既有场景代表公共点上无退化”。不得表述为八场景完整公共解已经恢复、旧公共集全部保留或未见数据泛化已经成立。

## 当前停止边界

统一策略、相关机制测试、24 条定向记录回执和只读注册表已经冻结。尚未执行：

1. 八场景 7200 cell 响应面重算；
2. 旧公共集 `C_old` 与新公共集 `C_new` 的 S/A/B/F 保护等级审计；
3. 新响应面上的两训练一留出三折选择器；
4. 未见记录或跨个体确认性验证。

用户已经确认下一步使用同一无标签统一 profile，对八场景二十四记录补齐冻结 300 点 Physical4D 面板，即 `24 × 300 = 7200` 个新算法 cell；旧算法 solver report 不能作为新响应面复用。本对话在生成、独立核验并交接完整响应面资格包后结束，不在此处设计或执行选择规则，也不裁决论文科学身份。启动完整重算前仍需冻结实验身份、产物隔离、运行预算和响应面阶段的晋级/中止条件。
