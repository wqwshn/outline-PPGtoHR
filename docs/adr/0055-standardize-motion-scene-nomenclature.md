# 统一八个运动场景的规范英文名称

历史拼音 token 已进入原始记录名、缓存主键、冻结回执和实验哈希，追溯重命名会破坏复现身份；但继续把它们用于图表和论文又会造成 `Xiezi`、`Writing`、`Keyboard`、`Boxing` 等不一致表达。因此保留历史 token 作为兼容键，并为新分析和面向读者的内容统一采用 Handwriting、Rope Skipping、Handgrip、Typing、Running、Jumping Jacks、Burpees 和 Punching，以及对应缩写和 snake-case 代码 ID。所有软件展示入口读取同一公共术语注册表，历史实验身份不因名称规范化而改变。
