# Use mechanism-level route audits for heart-rate algorithm changes

Accepted. Recent v2 heart-rate work will be reviewed and documented as mechanism-level route audits rather than as a flat list of commits or final AAE changes. Each mechanism must record its motivation, implementation boundary, expected benefit, observed benefit, known regressions, surviving output evidence, and keep/redesign/disable recommendation. A mechanism is not considered retained only because it improves one cohort: it also needs window-level diagnostics, path-verifiable experiment outputs, and non-regression evidence on relevant external or cross-person samples. This is especially important for post-motion and motion-stage policies, where total AAE can hide trend failures, stale output indexes, or cross-person drops caused by choosing the wrong tracking route.
