# 在通用研究分支收尾 LYX 跨佩戴开发阶段

LYX 八场景跨佩戴开发阶段以原始固定面板 `19/24`、后验开发过程 `21/24 → 23/24 → 24/24` 和最终获选开发面板 `24/24` 的双层结果账本收尾。最终状态固定为 `EIGHT_SCENE_24_OF_24_POSTHOC_CURATED`；当前算法、选择器、Physical4D 空间、固定五秒六门和获选面板停止继续针对同一候选池调优。该结论只关闭 LYX 开发阶段，未来未见记录、跨个体或前瞻采集验证必须另建实验身份。

`codex/lyx-bo-space-generalization` 作为本研究的正式收尾主线，在来源分支完成收尾提交后以 fast-forward 承接 `codex/lyx-tiaosheng-curated-panel` 的完整证据链。21/24、23/24 和 24/24 分支继续保留为过程节点，直到主线验收完成；是否进入 `main` 另行决策，不与本次研究分支收尾绑定。目标工作树中既有的未提交图件改动属于独立用户状态，归并过程不得覆盖或擅自纳入本次提交。

收尾采用空间优先的最小缓存归档：全部 Git 正式证据永久保留；仅保留正式文件仍直接引用且当前存在的 solver report 目录，其余 LYX solver/ACC 响应面缓存、任务临时目录和语言运行缓存可以在生成保留清单与清理回执后删除。保留项必须先汇集到正式主工作树并记录原路径、归档路径、引用来源、大小和哈希，才允许移除过程工作树；历史上已经缺失的引用路径如实登记，不以补算改写既有回执。原始数据和未被明确分类为缓存的大型实验输出不在本轮删除范围内。

最终 `main` 同时接纳 LYX 收尾和两个已完成的跨个体研究分支。`codex/lyx-bo-space-generalization` 继续只承接 LYX 证据；`main` 在保存根工作树现有内容后合入该分支，再合入 `codex/candidate-bank-calibration-selection`，后者已经包含 `codex/lyx-cross-subject-evaluation` 的完整历史。两个跨个体实验仍固定引用其分支点 `788c5f6`，不得因进入新 `main` 而追溯改写为 24/24 身份、重新计算或重新解释；未来若使用收尾后的算法身份继续研究，必须建立 v2 实验。

LOSO 工作树约 25.39 GiB 的 solver cache 和 Candidate Bank 约 0.57 GiB 的自有 cache 不属于本轮 LYX 清理范围。Candidate Bank 直接复用 LOSO cache，因此两个跨个体工作树和缓存继续保留。LYX 的 21/24、23/24、24/24 过程工作树只在最小 report 集完成归档与哈希核验后移除，对应分支引用继续保留。
