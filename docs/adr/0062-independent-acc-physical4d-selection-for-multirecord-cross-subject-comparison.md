# 为多记录跨个体对照独立选择 ACC Physical4D 坐标

完成 `cross_subject_multirecord_hf_loso_v1` 后，ACC 不再只重放每折的 HF 获选坐标，而是在相同 143 条面板、四十八个成组 LOSO 折、冻结 300 点 Physical4D 空间和固定 5 秒评价口径下，使用五名训练受试者的 ACC MAE 独立选择坐标。ACC 先在受试者内部平均重复记录，再依次最小化五人中的最差受试者均值、五人均值和冻结坐标顺序；它不使用历史 Lite HF 六门、留出数据或 ACC 独立时延。

该对照继续在现有跨个体工作树与分支上实现，但使用新的实验身份、ACC 紧凑账本、选择回执和验证回执；既有 HF 账本、坐标和报告保持只读。正式比较同时保留 HF(θHF)、HF(θACC)、ACC(θHF) 和 ACC(θACC)，四格在坐标冻结后使用同一记录级可靠窗口交集重评；对角线是端到端主结果，非对角线只解释参考信号与参数错配，不允许事后择优形成新路线。

这一决定以新增 42,900 个 ACC 响应单元和定向物化四格轨迹为代价，换取与跨佩戴研究一致的训练侧独立调参机会，并避免把 HF 的参数适配优势误写成参考信号优势。实验不加入 HF+ACC、ACC 专属资格门、性能条件化删样本或参数空间扩展；这些问题如需研究必须另建实验身份。
