# ADR-0043：冻结4D结果后用全段MAE微调逐记录时延

- 状态：Accepted
- 日期：2026-08-19
- 关联任务：GitHub Issue #117

实验继续冻结提交 `0cd2a82a309112866e1727a0ad5761fe92d4e91c`、`smooth_win_len=5`、开启 rise lineage 的 `legacy_v1` 确认策略以及 `suppressed_protected_continuous_visibility_v1` 连续可见性。现有跨个体数据集仍来自既有 LYX 完整网格和非 LYX `3×40` BO-120 的门槛筛选：八个场景各六名不同受试者、每场景包含 LYX、共48条互不重复记录。本轮不重做这项筛选。

physical4D 搜索的职责是确定求解参数，评价时延不应成为 trial 内变量。现有跨个体数据集的48条记录及其已选4D坐标保持冻结；每条固定预测轨迹只在搜索结束后，用原始 HR_ref 于 `4.0/4.5/5.0/5.5/6.0 s` 五个偏置上比较全段可靠窗口 MAE。五个偏置使用共同有效窗口交集，先取最小者；完全并列时优先最接近5 s，再选择较小值。由于5 s属于候选，原始全段 MAE 最小者不会差于固定5 s。

这项微调不重新运行 solver 或 BO，不从既有 trial 中重选4D坐标，也不改变48条记录的数据集组成。完整经典门槛在新偏置下重新计算。若原始全段 MAE 最小偏置未通过门槛、而该记录上一轮 R-all 偏置在同一冻结轨迹上重新评价后通过，则正式有效偏置回退到上一轮值；除此之外门槛不触发重选。正式更新结果使用共同窗口MAE；原评价器按各偏置最大可用范围计算的指标用于门槛判断及兼容性报告。

此前的运动前/恢复段 R-all 静息标定属于算法开发过程，不再作为最终机制。执行收尾时直接覆盖本实验根目录中的派生偏置清单、数据集卡片、结果汇总、验证回执和结果报告；底层 solver report、内容缓存、BO逻辑历史、数据哈希和固定4D坐标保持不变。Git历史继续提供开发过程的追溯。本轮仍只筛选并更新数据集结果，不执行 LOSO。

2026-08-19 的收尾诊断发现 `run2_LZJ_0711` 的原始全段 MAE 最小偏置由上一轮4.0 s变为5.0 s后，完整MAE和运动MAE虽均改善，但运动尾端只有两个连续非 E10 恢复窗，因而新增 `right_censored_e10` 失败；4.0 s下存在三个连续恢复窗并通过门槛。该事实促成本 ADR 加入上述门槛保留回退。回退必须基于同一记录已冻结的上一轮偏置与重算门槛，不能按记录名硬编码。
