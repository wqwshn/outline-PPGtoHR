# ADR-0043：冻结4D结果后用全段MAE微调逐记录时延

- 状态：Accepted
- 日期：2026-08-19
- 关联任务：GitHub Issue #117

实验继续冻结提交 `0cd2a82a309112866e1727a0ad5761fe92d4e91c`、`smooth_win_len=5`、开启 rise lineage 的 `legacy_v1` 确认策略以及 `suppressed_protected_continuous_visibility_v1` 连续可见性。现有跨个体数据集仍来自既有 LYX 完整网格和非 LYX `3×40` BO-120 的门槛筛选：八个场景各六名不同受试者、每场景包含 LYX、共48条互不重复记录。本轮不重做这项筛选。

physical4D 搜索的职责是确定求解参数，评价时延不应成为 trial 内变量。现有跨个体数据集的48条记录及其已选4D坐标保持冻结；每条固定预测轨迹只在搜索结束后，用原始 HR_ref 于 `4.0/4.5/5.0/5.5/6.0 s` 五个偏置上比较全段可靠窗口 MAE。五个偏置使用共同有效窗口交集。每个偏置还必须对候选和基线使用同一偏置复评冻结经典门槛。只要存在门槛通过项，就在通过项中选择共同窗口 MAE 最低者；五项全不通过时仍选择全局最低 MAE，并记录 `no_gate_passing_time_bias_candidate` 风险。完全并列时优先最接近5 s，再选择较小值。

这项微调不重新运行 solver 或 BO，不从既有 trial 中重选4D坐标，也不改变48条记录的数据集组成。选择合同固定为 `gate_aware_full_mae_time_bias_v3`，门槛合同固定为 `multiperson_joint_screening_gate_v1`。该门槛逐偏置要求：频谱与双级 HF 身份完整、轨迹稳定、候选 L10 不超过 `max(10, baseline L10 + 2)`、候选 L20 不超过 `max(2, baseline L20)`、候选完整 MAE 相对基线不恶化超过2 BPM、右删失 E10 恢复计数为0、绝对 L10 不超过20，并保持真实上升适用性一致且适用时低估量相对基线不恶化超过2 BPM。正式选择使用共同窗口MAE；门槛指标按各偏置自身最大参考重叠范围计算。两者口径不同但在一个版本化选择合同中绑定。

此前的运动前/恢复段 R-all 静息标定属于算法开发过程，不再作为最终机制或未来输入。旧 R-all 偏置只保留为历史对照字段，不能参与选择。执行收尾时直接覆盖本实验根目录中的派生偏置清单、数据集卡片、结果汇总、验证回执和结果报告；底层 solver report、内容缓存、BO逻辑历史、数据哈希和固定4D坐标保持不变。Git历史继续提供开发过程的追溯。本轮仍只筛选并更新数据集结果，不执行 LOSO。

2026-08-19 的收尾诊断发现 `run2_LZJ_0711` 的原始全段 MAE 最小偏置为5.0 s，但它触发 `right_censored_e10`；附近存在门槛通过偏置。该事实促成本 ADR 从历史 R-all 回退修订为上述五偏置门槛优先规则，使当前记录和未来新记录使用同一机制。若未来五个偏置全部失败，风险只作显式记录，不把记录自动称为不合格。
