# 最小交接重新定位消融（Issue #62）

## 结论

本轮为 NO-GO，不选择重新定位机制。四个候选均无 down-up bounce、无错误 hard switch，且独立 reset 的逐窗数值、raw top-5 和完整 trace 完全不变；但是上一轮 N5 已达到 2.999 BPM 的 `bobi2` 在所有最小候选中退化到 8.2–8.4 BPM，违反“已经达到 MAE<3 BPM 的救援样本不得因精简失守”的冻结门槛。

`minimal_reanchor` 是满足“最多一种重新定位”约束时的最佳诊断方案，但不能晋级。A2+重锚仅作为判断两种机制是否有增量的诊断组合，不是可落地候选；它同样没有保住 `bobi2`。

## 实验口径

- 输入参数：N5 HB24 Lite 1×40 批次中每条样本的同一份 Lite 配置。
- 计算路径：每个候选重新执行完整 `solve_v2`，不把 N5 已含旧状态机的归档 Final 当作新 adaptive 基线。
- 代表性池：4 条原始失效样本 `bobi2/kaihe2/kaihe3/tiaosheng3`；6 条正常哨兵 `run1/run2/woli1/woli2/xiezi2/jianpan3`。
- 固定因子：PPG 启动门、Final 弱先验、`target_consumable`、18 BPM gap rescue、6 BPM/2 窗 stable crossover 全部相同；仅重新定位模式变化。
- 选择顺序：连续性与独立 reset 不变性 → 相对主分支正常池门槛 → 已有 `<3 BPM` 救援保持 → 正常池 MAE → 重新定位数量 → 失效池 MAE → 总体 MAE。

## 四组结果

| 候选 | 重新定位数 | 失效池 MAE | 正常哨兵 MAE | 总体 MAE | bounce | 错误 hard switch |
|---|---:|---:|---:|---:|---:|---:|
| 无重新定位 | 0 | 4.061 | 7.650 | 6.214 | 0 | 0 |
| A2 | 1 | 4.112 | 7.586 | 6.197 | 0 | 0 |
| 受控重锚 | 1 | 4.061 | 5.667 | 5.025 | 0 | 0 |
| A2+重锚 | 2 | 4.112 | 5.540 | 4.969 | 0 | 0 |

主要差异来自 `run2`：无重新定位为 24.50 BPM、A2 为 24.88 BPM，而带重锚的两组均为 12.59 BPM。A2 对这一旧轨迹不可达问题没有独立作用，重锚才是有效因素。四组首次切换范围分别为 138–236 s、137–227 s、138–210 s 和 137–210 s，所有代表样本均发生一次不可逆交接。

## 与历史主分支比较

受控重锚诊断候选将 4 条失效样本平均 MAE 从 28.702 降至 4.061 BPM；6 条正常哨兵从 6.532 降至 5.667 BPM。正常哨兵没有单条退化超过 2 BPM；最大退化为 `run2` 的 +1.605 BPM。尽管池级门槛通过，`bobi2` 相对 N5 从 2.999 退化到 8.221 BPM，构成自动失败。

| 失效样本 | 主分支 MAE | 受控重锚 MAE | 状态 |
|---|---:|---:|---|
| bobi2 | 18.352 | 8.221 | 优于主分支，但丢失 N5 的 2.999 BPM 救援，失败 |
| kaihe2 | 62.097 | 1.417 | 已解决 |
| kaihe3 | 21.899 | 4.564 | 明显改善，但仍未达到 3 BPM |
| tiaosheng3 | 12.461 | 2.043 | 已解决 |

`bobi2` 与 `kaihe3` 客观标记为未达到应用门槛；本轮不为它们新增质量门、先验失效条件或样本专用阈值。

## 复杂度与后续决定

受控重锚候选平均出现 4.1 个外部控制状态、3.1 次转换，只使用 1 个重新定位机制；A2+重锚需要 2 个。由于所有候选均违反已有救援保持门槛，复杂度排序不会覆盖该失败。

本轮结论为代表性池 NO-GO：不把任何重新定位方案传给完整 HB24 固定参数验收，也不允许运行 Lite BO 1×40。`bobi2` 的损失客观说明，旧 N5 收益并不只来自“选哪一种重新定位”，最小状态机删除的其他控制语义仍有承载收益；本 Issue 禁止新增门或阈值，因此不在此继续补丁化。
