# 完整三折最终选择性能图验收规范（v1）

- 状态：Accepted
- 合同 ID：`threefold_selected_performance_figure_v1`
- 关联决策：ADR-0047
- 首次应用：LYX 八场景统一算法响应面三折评估

## 1. 适用范围

当一个实验完成按场景分组、每场景三条记录的 leave-one-record-out 三折评估时，本图是主要验收结果之一。它展示冻结主选择器实际交付的留出性能，不承担选择、调参或门槛裁决。

图件必须在存在合法主选择器 top-1 时绘制，无论该 top-1 是否通过留出门槛。不得只画通过折，也不得在失败后改画留出记录上的 oracle 最优候选。

若某折没有合法 top-1，源数据必须保留缺失状态且不得制造替代数值；图仍应交付其他合法折，并在配套结果表中说明缺失原因。本规则不允许“为了画满图”引入 plot-only 选择器。

## 2. 冻结数据模型

每个绘图点必须绑定：

- `experiment_id`；
- `scene`；
- `fold_id` 与 `holdout_record_id`；
- `primary_selector_id`；
- `coordinate_id`；
- 评价合同与评价偏置；
- `mae_bpm`；
- 主折状态；
- 输入 report、reference、freeze receipt 与 reveal receipt 的 SHA-256；
- 若有对照臂，对照身份及其相对主臂的允许差异。

图只读取正式逐折结果表，不自行重新选择坐标、偏置或规则。场景汇总必须由同一份逐折表机械生成。

## 3. LYX HF/ACC 首次应用口径

LYX 八场景首次应用固定两组数据：

- `HF`：主选择器 top-1 的 `gate_aware_full_mae_time_bias_v3` 最终 MAE；
- `ACC`：同一 top-1 完全复用 HF 的 Physical4D、机制、平滑和 HF-v3 偏置，只把自适应参考组合由 HF 改成 ACC 后的 MAE。

ACC 不独立选参、不独立选择时延、不参与固定 5 秒 HF 主折裁决。逐折结果表同时保存 HF/ACC 固定 5 秒值及上述最终配对偏置值，主图只显示最终配对偏置值。

## 4. 统计与排序

每个“场景 × 组别”必须恰好使用该场景三个合法留出折：

- 柱值：算术均值；
- 误差棒：样本标准差，`ddof=1`；
- 原始点：三个逐折值全部显示；
- 不计算置信区间、显著性检验或把 24 折宣称为独立统计重复。

LYX 图按 HF-v3 场景均值升序、自上而下排序；均值完全相同时按冻结场景名排序。每个场景中 HF 固定在 ACC 上方。

## 5. 视觉合同

- 图型：单面板横向分组柱状图；
- x 轴从 0 开始，所有场景共享同一连续尺度，禁止截断和断轴；
- HF 使用暖橙，ACC 使用冷蓝；误差棒使用深灰或黑；
- 三折点必须清晰可见，且通过位置、描边或形状提供灰度冗余；
- 不绘制总标题、结论句、通过率、解释段落、箭头或装饰性标注；
- 只保留场景标签、坐标轴标题与单位、刻度、组别图例等理解数据所必需的文字；
- 不在柱尾写均值±标准差，精确值由源 CSV 与结果表承担；
- 字体、线宽、图例与间距在八场景下不得重叠或裁切。

心率任务的建议映射为：HF `#E07B39`、ACC `#4C78A8`、误差棒 `#2F2F2F`、网格 `#D9D9D9`。颜色可因期刊要求微调，但主/次层级、色盲安全和灰度可辨性不得丢失。

## 6. 导出合同

Python 是唯一允许的绘图后端。每次完整三折验收必须交付：

- `*.png`：600 dpi；
- `*.svg`：文本保持可编辑；
- `*.pdf`；
- `fold_plot_data.csv`：逐折绘图源数据；
- `scene_plot_summary.csv` 或等价 JSON：均值、样本标准差、折数和排序键；
- `figure_contract.json`：本实验对本规范的实例化；
- `figure_manifest.json`：输入、脚本和所有输出的 SHA-256；
- `figure_qa.json`：程序检查与渲染后视觉检查。

建议以 `183 mm` 双栏宽度导出；高度由场景数决定。PNG 是强制验收预览，SVG/PDF 是正式矢量伴随件，三者必须来自同一次绘图运行和同一份源数据。

## 7. QA 与失败条件

验收程序至少核对：

- 场景、组别、折数与源结果一致；
- 每根柱的均值、`ddof=1` 标准差和三个点可由源 CSV 复算；
- 排序、组内上下位置和图例映射符合合同；
- PNG 实际 dpi 与像素尺寸满足 600 dpi 输出；
- SVG 文本可编辑，PDF/PNG/SVG 文件均非空且哈希已登记；
- 没有标题、解释性文字、裁切、重叠、缺字、断轴或隐藏异常值；
- 灰度预览中仍能区分两组。

任一绘图数据与正式逐折结果不一致、失败折被遗漏或替换、统计量不可复算、必需格式缺失、ACC 对照未遵守配对身份，均判图件验收失败。图件失败不改写三折数值结果，但完整实验交付不得标记为完成。
