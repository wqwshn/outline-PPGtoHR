# Triage labels

Matt Pocock skills 使用五个标准 triage 角色。本文档把这些角色映射到本项目 GitHub issue/PR 中实际使用的标签。

| Matt skills 角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估、归类或确认优先级 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，适合交给 agent 独立处理 |
| `ready-for-human` | `ready-for-human` | 信息完整，但更适合人工实现或决策 |
| `wontfix` | `wontfix` | 明确不处理或不计划采纳 |

当某个 skill 提到 triage 角色，例如“应用 AFK-ready 标签”或“标记为等待信息”，应使用上表右侧的本项目标签。

如果 GitHub 仓库后续改用中文标签或已有标签体系，只需要更新本文件右侧标签列。
