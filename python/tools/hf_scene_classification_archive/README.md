# HF 运动场景分类：冻结方法源码

这里收录 2026-10-05 至 2026-10-07 的 v1–v5 方法与核验源码，用于给已完成的探索补齐 Git 版本记录。首次收录按字节复制，保持执行时的参数、划分、公式和历史 SHA-256；`.gitattributes` 禁止对这些 Python 文件做换行转换。

目录镜像本地 `data/experiments/` 的实验身份。v1 的 P0、训练和绘图入口仍在 `python/tools/`；这里补存独立核验。v2 收录准备、固定人工特征矩阵和独立核验；v3 收录合成预检、CNN/CNNLSTM 与独立核验；v4 收录 119 条记录 LOSO、动态 HF 消融及各自核验；v5 收录输入审计、统一预处理矩阵及独立核验。

这些是历史源码，不是新的分类运行入口。原脚本用 `__file__` 所在目录定位输入和输出，部分脚本还保留原工作区绝对路径；**不要直接在此归档目录运行它们**。核查既有实验时使用对应 `data/experiments/` 中的原脚本。需要从 Git 恢复源码时，应先比较本地冻结回执，再复制到相应的本地实验路径，不能覆盖不同指纹的文件，也不能对已冻结目录重新执行 `--prepare`。

神经实验原执行环境为 conda `DL`（PyTorch 2.5.1+cu121）；基础特征及普通核验优先使用 `ppg-hr`。没有把神经依赖加入心率包，也没有改变心率算法或 GUI。

逐记录/逐窗口指标、模型、预测、图表、机器回执、完整报告与含观测结果的报告生成脚本继续保存在本地实验目录，不进入 Git。三个大型窗口缓存已作本地无损压缩归档，运行依赖它们的历史核验前须按阶段收尾文档恢复。
